## 🌟 電子書網站特色功能

1. **護眼閱讀體驗**：
   * 三大主題自由切換：護眼紙張（暖黃 Sepia）、清新純白（Light）、深邃星空（Dark 夜間模式）。
   * 四段字級調整（小、中、大、特大），行距自動最佳化。
   * 閱讀進度即時頂部進度條顯示。
2. **自動進度存檔**：
   * 透過瀏覽器本地儲存（`localStorage`），自動記錄讀者上次閱讀章節與閱讀位置，隨點隨續讀。
3. **小偵探互動實驗室 (Puzzle Lab · 雙卷 7 大科學實驗)**：
   * 🌊 **第二卷海事與光學實驗室（全新登場！）**：
     * **國際海事信號旗語解碼機（ICS Flag Decoder）**：支援 A-Z 向量旗幟即時編碼、預設密碼與旗語競猜。
     * **阿基米德浮箱力矩平衡天平**：設定三組水銀浮箱與不同力臂，達成 6:3:2 力矩平衡鎖死 100 ATM 水門。
     * **布魯斯特角偏光透鏡模擬器**：手動旋轉偏光轉輪至 45.0°，消除大氣逆溫上蜃景眩光與全息陷阱。
     * **畢達哥拉斯五度相生律風琴諧波器**：運用 Web Audio API 原生合成純律音調，同步吹響 Do-Fa-Sol-High Do 天琴和弦平息水母群。
   * 📘 **第一卷校園與機械電路實驗室**：
     * **A1Z26 密碼雙向轉換器**：快速英數互換還原失竊代碼。
     * **布林代數閘刀開關模擬器**：驗證紅藍黃閘邏輯電路輸出。
     * **齒輪傳動比動態計算機**：計算主從動輪齒數與最簡整數比。
4. **沉浸式精確閱讀書籤系統 (Precision Reading Bookmarks · 全新登場！)**：
   * **閱讀中一鍵放入書籤**：閱讀任何章節時，點擊頂部浮動工具列「🔖 放入書籤」，精準記錄當前像素高度（`scrollY`）、章節百分比以及視窗中央正在閱讀的段落摘要。
   * **精確像素無縫回跳**：點擊任一書籤，無論是在首頁、其他章節還是各個子頁面，自動平滑捲動回到當初的**精確閱讀位置**，並輔以金黃色光芒聚光動畫。
   * **全域書籤管理與首頁續讀卡**：頂部導覽列提供「🔖 書籤」彈窗隨時管理或刪除書籤；書庫首頁更會自動展示「上次閱讀書籤快捷卡」，一鍵無縫接續冒險！
5. **閱讀成就勳章系統**：
   * 讀完指定章節即可自動解鎖專屬勳章，並伴隨輕快音效與提示！
6. **多語系出版架構 (Multilingual Publishing · 第一章首發！)**：
   * 🇹🇼 **中文原版**：原創繁體中文版少兒科幻小說。
   * 🇬🇧 **英文旗艦版**：針對 9～13 歲讀者編寫之高品質英文譯本《Chapter 1: The Stolen Twenty-Four Hours》，對話生動且節奏明快。
   * 🌐 **中英對照平行版**：段落一一平行對齊，下方配以斜體雅緻英文字句與金黃色指引線，兼顧故事沉浸度與雙語學習效益。
   * **即時切換膠囊**：閱讀器頂端提供直覺之「中 / EN / 中英」切換膠囊，隨選隨讀並自動記憶讀者偏好。
7. **多書擴充架構**：
   * 採用 JSON 資料驅動，未來撰寫新書只需加入資料即可自動上架首頁書架。

## 💻 本地預覽與運行

本專案為零依賴的純靜態網站，無需安裝伺服器或編譯步驟：

1. **直接開啟**：
   * 直接在檔案總管中雙擊開啟 `index.html` 即可在瀏覽器開始閱讀！
2. **使用本機輕量伺服器（可選）**：
   ```bash
   # 使用 Python 內建伺服器
   python -m http.server 8000

   # 或使用 Node.js npx
   npx serve .
   ```
   瀏覽器造訪 `http://localhost:8000` 即可預覽。

## 🚀 部署至 GitHub Pages 步驟

本專案已在 `.github/workflows/deploy.yml` 預先配置自動化部署工作流：

### 步驟 1：在 GitHub 上建立一個新的倉庫 (Repository)
* 例如取名為 `gearnovel` 或 `story`（設為 Public 或 Private 皆可）。

### 步驟 2：將本機代碼推送到 GitHub
在終端機中執行以下指令（將 `<your-username>` 和 `<your-repo>` 替換為您的 GitHub 帳號與倉庫名稱）：

```bash
# 加入遠端倉庫地址
git remote add origin https://github.com/<your-username>/<your-repo>.git

# 推送到 GitHub main 分支
git push -u origin main
```

### 步驟 3：在 GitHub 啟用 Pages 功能
1. 進入您在 GitHub 上的該倉庫頁面。
2. 點擊頂部的 **Settings** ➡️ 左側選單找到 **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 下拉選單中：
   * 選擇 **GitHub Actions**（系統會自動識別我們已寫好的 `deploy.yml`）。
4. 大約 1～2 分鐘後，工作流執行完成，頁面上方將顯示您的專屬網站網址：
   `https://<your-username>.github.io/<your-repo>/`

任何人點擊該網址即可在手機、平板或電腦上暢讀這部少兒科幻小說！
