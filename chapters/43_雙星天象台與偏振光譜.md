# 第十一章：雙星天象台與偏振光譜

## 一、深空遠征的密碼電報

天穹鐘樓的極限危機解除後，盛大的加冕典禮為琉光星港迎來了一段寧靜、溫暖而明亮的美好時光。

在舊城區工匠巷深處的晨光堂工坊裡，初秋午後溫暖的陽光穿透高大的拱形彩繪玻璃，將一抹抹斑斕絢麗的幾何光斑輕柔地鋪灑在厚重的紅橡木工作臺上。空氣中瀰漫著剛出爐的蜂蜜柚子茶香，以及高級薰衣草鐘錶油那令人安心的草本芬芳。剛剛榮膺星港最年輕「青年首席星軌修復師」的十三歲少女<u>采婭玆</u>，正繫著洗得乾淨整潔的深褐牛皮圍裙，單手拿著一柄精雕細琢的游標卡尺，專注無比地校準著一具微型自律星盤的雙金屬游絲擒縱輪。在她白皙的指尖下，微米級的齒輪發出如清晨露珠滴落般悅耳的「滴答」聲。

在長條工作臺的另一端，同樣佩戴著純金雙子星軌桂冠徽章的跳級數學天才少女<u>林漪姉</u>，正握著一柄吸墨流暢的鍍銀鋼筆，在展開的巨幅羊皮紙航海圖上飛快推演著外環空域的微積分天體攝動軌道。而在兩人身後，身著深藍色引航防風夾克的十四歲少年首席引航官<u>罧貁銁</u>，正倚靠在敞開的雕花窗櫺旁，手裡握著一塊細膩的黃銅油石，專注地替雙人引航帆艇的微風感測舵翼打磨流線型邊緣。機械小狐狸<u>露露</u>舒服地蜷縮在陽光最充足的黃銅托盤裡，銀白色的金屬長尾微微晃動，喉嚨裡發出如鐘擺律動般安詳愜意的輕微咕嚕聲。

後院的門簾被輕輕掀開，老掌門<u>采修誠</u>端著一盤金黃酥脆的熱騰騰松子酥餅走進店堂，滿是皺紋的臉龐上掛著無比慈愛的笑意：「孩子們，先停下手裡的活計，喝杯熱茶歇一歇吧。自從你們在星耀大賽與天穹鐘樓一戰成名以來，整個星港各大航海公會與商會的維修訂單幾乎要把晨光堂的門檻踩破了。但做鐘錶和做人是一個道理，若發條始終擰得太緊，內部的金屬晶格反而最容易因過載應力而產生隱性疲勞。」

「謝謝爺爺！您烤的松子酥餅永遠是全星港最美味的！」<u>采婭玆</u>抬起頭，深琥珀色的眼眸中泛起燦爛的笑靨，伸手剛要接過一塊酥餅。然而，就在她的指尖觸碰到瓷盤邊緣的千分之一秒——

「滋——滋——滋！滴！嗒！滴！嗒！」

工坊東側角落裡那具專門連接萬米平流層長波通訊中繼站的古老「全息日照通信機（Heliograph）」，頂部的雙曲面黃銅拋光反射鏡突然開始以每秒三十轉的高速瘋狂旋轉！伴隨著高頻壓電陶瓷激發出的刺耳嗡鳴，一道道劇烈閃爍的藍白色偏振光束如同利劍般刺破空氣，在天花板的石膏浮雕上投射出一輪象徵著特級最高危急等級的刺目猩紅光暈！

<u>林漪姉</u>手中的銀筆猛然懸停在半空中，少女清澈如寒冰的眼眸驟然收緊：「這不是普通的商務電報……這是來自星港最外緣、孤懸在兩千公里外『雙星天象台』的特級求援信標！」

## 二、雙星掩食與偏振光暴

「嗒嗒嗒嗒——」日照通信機的打孔純銅感光紙帶以驚人的速度吐出，長達三公尺的打孔碼在工作臺邊緣如瀑布般垂落。

<u>罧貁銁</u>敏捷地一步跨上前去，扯下通訊紙帶，神色凝重地快速譯讀著光學莫斯電碼：「『緊急通報全星港最高評審委員會：天樞外環雙星系統（琉光甲星與琉光乙星）今日正午進入五百年一遇的偏心率共振掩食！兩顆超大質量恆星在近日點發生強烈潮汐摩擦，釋放出超過正常通量數萬倍的非對稱帶電星風，激發大氣高層微晶冰雲與游離星塵產生全天域強烈線偏振光暴！天象台主聚光望遠鏡光柵遭遇全光學飽和，外環三大遠航主空域的光學導航羅盤徹底失靈！已有十二艘深空勘探帆船迷失在偏振光霧中，氧氣儲備僅剩七十二小時！』」

電報的最末尾，印著一枚由雙星交匯幾何光軌構成的古老印記，落款人正是天樞科學院前任榮譽院長、現任雙星天象台總台長——<u>莫拉長老</u>！

「偏振光暴……」<u>采婭玆</u>微微蹙起秀眉，腦海中迅速檢索著自幼在晨光堂翻閱的古代光學與天體力學筆記，「普通自然陽光是橫波，其電場向量在垂直於傳播方向的所有空間平面上均勻、隨機地高速震盪；但當強烈的星光穿透具有強磁場的高空冰晶微粒與星塵雲層時，散射過程會將電場向量嚴格限制在單一特定方向的平面內，轉化為能量高度集中的『線偏振光』！」

「沒錯，而這正是航海員最致命的夢魘！」晨光堂的厚重雕花橡木大門被猛然推開，天樞科學院長<u>林嚴</u>帶著兩位資深助理大步流星地跨入店堂。院長神情無比嚴肅，手中緊握著一份剛從科學院中央射電觀測塔印出的大氣偏振光譜分析圖：

「外環大氣層中散射的偏振背景眩光強度，已經達到了正常天頂星光的八百倍以上！一般的航海偏振眼鏡在這種極限強光下，濾光層會在數秒內因光化學反應而徹底過載白化。領航員放眼望去，整個天地只剩下一片刺目冰冷、無法辨別方向的乳白色死寂光霧。所有的光學六分儀與星盤在強光下根本找不到雙星的微小光斑，更遑論測量恆星的軌道角速度！」<u>林嚴</u>院長深邃的目光落在了三位年輕的孩子身上，語氣莊嚴而充滿托付：

「<u>采婭玆</u>，<u>林漪姉</u>，<u>罧貁銁</u>。你們剛剛在天穹鐘樓證明了手感與算式的完美結合。科學院最高評審團全票決定，正式任命你們三人組成『深空第一特遣隊』，搭乘最新改裝的旗艦級遠航風帆戰艦『織光破浪號』，即刻啟程馳援雙星天象台！你們必須在七十二小時內解開雙星偏振光譜的物理規律，為迷失的船隊點亮生還的燈塔！」

## 三、馬呂斯偏振方程與都卜勒頻移

當天黃昏，一艘長達四十五公尺、通體覆蓋著輕質鈦鋁合金裝甲與金黃色鍛鐵骨架的巍峨遠航旗艦「織光破浪號」，雄渾無比地停泊在中央浮空軍港的三號深水起降泊位上。

這艘戰艦配備了三具最新型的超高壓等離子噴流引擎，能夠在萬米高空的高寒低壓環境中持續巡航。主甲板中央隆起一座由多面耐壓水晶拼裝而成的全透明天體觀測觀星圓頂。在觀星圓頂內部的核心工作臺上，<u>林漪姉</u>已經將她的便攜式全息微積分終端接入了旗艦的天體光譜儀。伴隨著一道柔和的翡翠綠光，全息光幕在三人面前優雅展開，清晰地投射出一套極其嚴密的波動光學偏振模型：

```

1. 線偏振光穿透檢偏晶體時的電場向量正交分解：
   E_transmitted = E₀ · cos(θ)
   （其中 E₀ 為入射偏振光電場振幅向量，θ 為偏振化方向與檢偏鏡透光軸之間的幾何夾角）

   I(θ) = I₀ · cos²(θ)
   • 當 θ = 0°（透光軸完全平行）：透光率達到理論極大值，I = I₀（100% 無損穿透）；
   • 當 θ = 90°（透光軸嚴格正交）：發生完全物理消光，I = 0（完全濾除背景雜散光！）；
```

「大家仔細看光幕上的干涉條紋！」<u>林漪姉</u>手中的雷射指示筆在兩條緊密糾纏的光譜曲線上畫出一個紅色圓圈，清澈如雪水的聲音在安靜的艦橋裡迴盪，「天象台之所以陷入全盲，是因為他們一直在用傳統的『標量減光片』！普通減光片只能等比例削弱所有光子，就像戴上一副墨鏡，白茫茫的眩光雖然變暗了，但兩顆恆星微弱的光斑也隨之消失了！」

「但是線偏振光是『向量』，不是標量！」<u>采婭玆</u>杏眼圓睜，腦海中瞬間將馬呂斯定律與齒輪傳動的幾何角度融會貫通，「大氣中散射的刺目眩光，其電場向量是整齊劃一地朝著同一個特定角度震盪的！只要我們在檢偏鏡的旋轉軸上，精確旋轉到與眩光電場方向夾角為 $\theta = 90^\circ$ 的正交位置，根據馬呂斯定律 $I = I_0 \cos^2(90^\circ) \equiv 0$，整片可怕的背景白霧將在瞬間被徹底消除！」

「太精闢了！而在消光後的純黑天幕下，雙星互繞產生的都卜勒藍移（琉光甲星）與紅移（琉光乙星）光譜，將會像黑絲絨上的藍寶石與紅寶石一樣，清清楚楚地分開！」<u>林漪姉</u>眼中滿是找到破局點的熾熱光芒。

## 四、旋轉方解石稜鏡與星角導航

「但是，在萬米高空的強氣流與強光衝擊下，普通的偏振塑膠膠片只要暴露在高溫強光下五分鐘，分子鏈就會受熱鬆弛形變，失去偏振各向異性！」站在舵輪旁的<u>罧貁銁</u>敏銳地指出關鍵問題，少年指著舷窗外狂暴的翻騰雲海提醒道。

「所以我們絕不用膠片——我們要用真正的光學傳家寶——『天然光學雙折射冰洲石方解石雙稜鏡』！」<u>采婭玆</u>自信地微微一笑，伸手探入隨身的黃銅工具匣深處，小心翼翼地取出了一枚巴掌大小、通體晶瑩剔透、呈現出完美無瑕菱面體幾何結構的天然冰洲石晶體。

那是晨光堂工坊珍藏三代的頂級天然光學方解石。方解石具有大自然中最神奇的雙折射率特性：當一束非偏振光穿透晶體時，晶體內部的各向異性晶格會將光束精準拆解為遵循司涅爾折射定律的『尋常光（o 光，Ordinary Ray）』，以及折射率隨入射夾角改變的『非常光（e 光，Extraordinary Ray）』。這兩束光的偏振化電場向量嚴格保持九十度正交，天生就是最完美的天然偏振光分離器！

<u>采婭玆</u>迅速戴上單目黃銅放大鏡，右手握著超硬質金剛石銼刀，左手用母貝游標卡尺精確測量方解石光軸與晶面夾角。機械小狐狸<u>露露</u>化身最默契的助手，金屬長尾敏捷地噴出一股冰涼細密的去離子水霧，在高速研磨時替晶體即時降溫防震。僅僅用了四十分鐘，一具由因瓦合金外殼精密包覆、底座配備了一百二十齒無間隙微調黃銅蝸輪的「超高精度旋轉偏振雙稜鏡」，便在少女修長靈活的手指下組裝完成！

「咔嗒！」

<u>采婭玆</u>身輕如燕地攀上觀星圓頂的主望遠鏡維修梯，將這枚沉甸甸的方解石雙稜鏡精準鎖死在主物鏡的光路焦點上。小狐狸<u>露露</u>鑽入鏡筒基座，靈活的金屬尾尖精準卡死在微調蝸桿的傳動齒輪上，等待著最終指令。

「戰艦正式切入外環雙星偏振光暴核心空域！」<u>罧貁銁</u>大聲通報數據。舷窗外，原本深邃美麗的星空突然被一層鋪天蓋地、狂暴肆虐的乳白色眩光完全吞噬，恐怖的八百倍光子輻射讓甲板上的探險隊員們發出陣陣驚呼，紛紛用手臂死死擋住護目鏡。

「<u>林漪姉</u>，計算當前大氣電場向量角度！」<u>采婭玆</u>在狂風呼嘯中大喊。

「冰晶氣溶膠散射電場偏振角為三十五點二度！依據馬呂斯定律，完全正交消光透光軸設定為——一百二十五點二度（$\theta = 90^\circ + 35.2^\circ$）！」<u>林漪姉</u>白皙的雙手在計算儀鍵盤上敲下最後一行指令，螢幕上的消光判定點瞬間變綠！

「<u>露露</u>，旋轉蝸輪三十五點三格，閉鎖檢偏光軸！」<u>采婭玆</u>一聲清脆指令。

小狐狸的金屬尾巴猛然轉動蝸桿，一百二十齒黃銅齒輪發出清脆悅耳的「卡嗒」咬合聲，分毫不差地鎖定在了一百二十五點二度的刻度線上！

下一秒，一幕震撼全艦所有探險隊員心靈的光學奇蹟驟然誕生！

原先狂暴肆虐、刺目欲盲的乳白色死寂光霧，在馬呂斯定律的零強度消光點（$I = I_0 \cos^2 90^\circ \equiv 0$）支配下，宛如被一柄無形的宇宙利刃徹底切除抹去！望遠鏡目鏡中的視野瞬間化作一片純淨無瑕、深邃透徹的永恆黑夜。而在這片純黑的天鵝絨畫布正中央，兩顆宛如天神眼眸般璀璨奪目的恆星——琉光甲星與琉光乙星，正散發著清澈優雅的星輝，清晰無比地浮現在眾人眼前！

更令人嘆為觀止的是光譜儀上的都卜勒讀數：琉光甲星的夫朗和斐鐵吸收線向著高頻紫色端平移了零點六奈米（藍移，視向速度 $v_r = -300\,\text{km/s}$，正朝著星港高速奔來）；而琉光乙星的吸收線則向著紅色端平移了零點六奈米（紅移，視向速度 $v_r = +300\,\text{km/s}$，正背離星港疾馳而去）！互繞雙星的軌道週期、速度向量與幾何相位，在旋轉方解石稜鏡的折射下被完完整整、精準到小數點後四位地捕獲鎖定！

## 五、解鎖 POLAR 密碼，遠征雙星雲海

「雙星軌道相位完全鎖定！大氣偏振折射角校準完畢！新航向——正北偏東十四度三分！」<u>罧貁銁</u>激動地放聲長嘯，雙手沉穩有力地將主舵輪推向預定航線。

旗艦的三具高壓等離子引擎爆發出歡快而磅礡的藍白光柱，長達四十五公尺的鋼鐵戰艦如同一頭矯健的雲海神鯨，破開狂暴的雲層與紊流，在漆黑深邃的夜空中劃出一道長達數百公里的金色光帶！在旗艦身後，原本迷失在乳白光霧中的十二艘深空勘探帆船，紛紛校準了艦載偏振濾鏡，整齊劃一地跟隨在金色光軌後方，脫離了致命的強磁引力漩渦！

就在這時，方解石雙稜鏡的核心光學分光鏡面上，由雙星交匯的尋常光與非常光交織聚焦，在半空中投射出了一行閃耀著深藍色星芒的 A1Z26 終極密碼序列：
