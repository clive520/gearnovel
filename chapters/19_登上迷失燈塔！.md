# 第十九章：登上迷失燈塔！

## 一、沸騰大洋的生死衝刺

天琴礁島的外海，海面已經不再是平靜的水銀，而是沸騰的深紅煉獄！

海底數千公尺處地熱熔岩的劇烈上湧，讓海面上噴發出一道道高達數十公尺的高溫硫磺熱泉。空氣中瀰漫著濃烈的燃燒瓦斯與刺鼻的臭氧，海面上漂浮著一層厚厚滾燙的浮石灰燼。

「轟隆隆隆————！」

遠方的海平面上，一圈巨大的環形下陷深淵，如同一隻張開在地表上的深海巨口，正以肉眼可見的速度將周圍數十公里的海水瘋狂吞入地心！

「海嘯前兆！那是地殼塌陷引發的**『深海超級黑洞』**！」

嵐雙手死死抓住青木齒輪號的舵輪，小麥色的手臂上青筋暴突。海鷗號已經被固定在戰艦側舷，她迎著撲面而來的滾燙水汽狂喊：

「整片千島齒輪海的潮汐系統已經全面崩潰！距離超級海嘯爆發……只剩下最後**兩小時四十五分**！」

「嗡————！」

就在這時，誠浩手中緊握的「十二面體星象儀」與「天琴座光學星盤」合體神器，突然在黃昏的天幕下爆發出一道直徑半公尺粗的純金色彩虹光柱！

這道凝聚了古代星穹力量的激光束，穿透了海面上翻滾的濃煙與毒霧，如同一條指引命運的金色鎖鏈，筆直地射向了十公里外那座隱沒在大裂谷深淵之中的青銅迷失燈塔！

「看！那是爺爺留下的光學引航道！」誠浩指著海面上被激光劈開的一道平靜水路大喊，「順著光束衝過去！」

「嗚————嘟————！！」

然而，就在青木齒輪號準備全速俯衝的同一秒，右側的火光中，黑潮重工那艘兩百公尺長的終極母艦「利維坦零號」，正調轉黑洞洞的十二具超空泡重型魚雷發射管，以泰山壓頂之勢封鎖了裂谷入口！

「鎖定目標！全彈幕集火，把裂谷入口徹底炸塌！」沈天成冰冷殘暴的聲音在公海廣播頻道中咆哮！

「巴克！小心左側魚雷！」將江舉著望遠鏡驚聲尖叫。

「老子看見了！！」

只見破浪鐵錨號那龐大粗糙的黑鐵艦身，竟然在這一瞬間毫無畏懼地迎著十二枚魚雷的彈道，全速橫切到了青木齒輪號的前方！

巴克船長站在高聳的艦首，身上的海軍大衣被烈火點燃了一角，但他那張滿是黑灰的臉上，卻綻放出一抹狂傲不羈的大笑：

「誠浩！少看扁我們千島海盜的骨氣！拯救世界是你們名門正派的事，但守住這座海門……是老子鐵錨幫的特權！」

「丁丁！把所有的發條水雷全給老子撒出去！給青木齒輪號爭取時間！！」

「發條全彈齊發！！」十歲的小蘿莉丁丁掄起大鐵鎚，滿臉淚水卻無比剛毅地一錘砸爛了整排連環引爆閥門！

「轟！轟！轟！轟！」

破浪鐵錨號以粉身碎骨的勇氣，在利維坦零號的魚雷群正前方引爆了一道長達數百公尺的衝天水下火牆，將所有的魚雷硬生生在半空中攔截殉爆！

「衝進去！誠浩！別回頭看老子！把老莫里斯和誠老爺子完好無損地帶回來！！」

巴克嘶聲力竭的咆哮聲，伴隨著鐵錨號反擊的滾滾砲聲，被海浪永遠拋在了身後。

誠浩眼眶通紅，指節泛白，對著通話管狂吼：「嵐！滿舵前進！衝進裂谷深淵！！」

## 二、重返迷失燈塔

「呼————撲通！！」

青木齒輪號順著激光導引的航道，以四十五度的極限角度俯衝扎進了深海裂谷之中。

深海的水溫與壓力在一瞬間飆升。

當船身穿過燈塔外廊厚重的水門、重重停泊在燈塔八十公尺高的懸空停機坪上時，整座青銅塔身正伴隨著地底傳來的沉悶震動劇烈搖晃。

老莫里斯早已等候在停機坪邊緣。老人的額頭上包紮著厚厚的紗布，手裡提著四套高溫地熱防護服與重型深潛呼吸面罩：

「你們做到了！天琴星盤拿到了？！」

「在這裡！」誠浩將合體的神器捧到老莫里斯眼前。

「太好了……快跟我來頂層控制台！」莫里斯大口喘著氣，領著眾人飛速衝進了八十公尺高空的水晶大廳：

「遠山在三千公尺地心留下的能量護盾，必須依賴這座燈塔頂部的『菲涅耳大透鏡』進行光子激勵！黑潮剛才的震動震偏了透鏡的共焦光軸，如果不把透鏡重新校準，星盤的光束就無法穿透三千公尺的地殼岩層！」

## 三、菲涅耳共焦聚焦與幾何光學

眾人踏入頂層大廳。

那座直徑達十公尺、由數千片水晶稜鏡環形咬合而成的巨型「菲涅耳主透鏡」，正靜靜矗立在中央。而在主透鏡的後方，是一面由沉重黃銅齒輪架托舉著的「副校準凹面準直鏡」。

此時，兩組透鏡的光軸嚴重偏離，原本應該匯聚成一束的光線，在天花板上散射成了一團混亂刺目的光斑。

「幾何光學共焦聚焦（Confocal Collimation）！」

葉旖緁一邊迅速套上防護服，一邊推動著海圖桌上的光學計算機：

```
【菲涅耳激光準直幾何光學方程】：
薄透鏡成像公式：
1 / f = 1 / d_o + 1 / d_i
無限平行激光束條件（直貫地心三千公尺不發散）：
像距 d_i ➡️ ∞，即 1 / d_i ＝ 0！

複合透鏡系統參數：
主菲涅耳水晶透鏡焦距：f₁ = +6.0 m（凸透鏡，會聚）
副金屬校準鏡焦距：f₂ = -2.0 m（凹透鏡，發散）

共焦無窮遠準直間距定理：
兩透鏡共軸且後焦點重合時，射出光束為完全平行光束！
共焦標準間距 d = f₁ + f₂ = 6.0 + (-2.0) = 4.0 m！

【齒輪軌道調節參數】：
當前導軌指針間距：d_curr = 2.5 m
需位移距離：Δd = 4.0 - 2.5 = +1.5 m（向後拉伸）
調節手輪傳動比：每搖動手輪整整一圈，導軌位移 0.5 m！
所需精確旋轉圈數：1.5 / 0.5 = 3 圈！
```

「**共焦間距四公尺！手輪搖動整整三圈！**」

旖緁大聲吶喊：「主凸透鏡焦距六米，副凹鏡焦距負兩米！只有當兩者相距剛好四米時，光線才會被壓縮成一束直徑只有十公分、強度提升一萬倍的**超級平行激光**，直貫三千公尺地心！」

「四米導軌！三整圈！」

誠浩、嵐、將江三人同時撲向導軌下方的重型黃銅手搖搖把！

「一、二……推！！」

齒輪在乾涸的機油中發出沉重的「喀啦啦」旋轉聲。

「一圈……一米！」將江咬緊牙關，滿臉通紅。  
「兩圈……一米五！」嵐的小麥色手臂青筋暴起。  
「最後半圈……三圈卡死！！」誠浩一聲怒吼，將限位插銷「當」的一聲狠狠拍進了黃銅刻度槽內！

「咔噠！」

副凹鏡在四公尺共焦點上精準鎖定！

## 四、神聖光束與三千米地心升降機

「誠浩！插入星盤！！」老莫里斯大吼。

誠浩捧起合體的星盤，對準菲涅耳透鏡正中央那處散發著幽藍光暈的基座，狠狠壓了下去！

「嗡————轟！！」

整座八十公尺高的迷失燈塔，在這一微秒內爆發出了一聲宛如遠古巨鐘撞響般的純淨長鳴！

數千片水晶稜鏡同時折射出億萬道刺目耀眼的金色光華，在四公尺共焦光軸的約束下，漫天散射的光斑在零點一秒內被暴力壓縮成了一道僅有手腕粗細、亮度卻宛如一千個太陽同時綻放的**「終極金色相干激光束」**！

「轟！」

這道金色光束帶著無可匹敵的穿透力，自燈塔頂端筆直向下轟出，穿透了八十公尺高的中空立體齒輪豎井，如同一柄神明的天罰之劍，狠狠貫穿了燈塔大理石基座中央那處深不見底的玄武岩深孔！

下一秒，大廳中央那塊原本堅固的地板，突然伴隨著一陣劇烈的液壓排氣聲緩緩下陷——

一座直徑達五公尺、四周包覆著十公分厚重型防熱鈦合金裝甲的圓形升降平台——**「三千米地心升降機（Geothermal Depth Elevator）」**，帶著沉悶的機械轟鳴，自地底緩緩升起！

「這部升降機直通地熱大廳！」老莫里斯一把拉開防爆艙門，將四個孩子推進艙內，「快進去！」

## 五、莫里斯的抉擇：斷後死鬥

然而，就在升降機門即將閉合的剎那——

「砰！嘩啦啦啦——！」

燈塔頂部厚達十公分的耐壓水晶觀測穹頂，突然被一記巨大的高爆聚能穿甲彈硬生生炸裂成漫天飛濺的晶瑩碎片！

十二根黑色的高壓抓鉤鋼纜自廢墟中呼嘯射入，牢牢釘死在大廳的梁柱上！

只見沈天成身穿一件泛著冰冷金屬光澤的外骨骼動力裝甲，手持電弧權杖，帶著八名全副武裝、手握高頻等離子切割刀的黑潮生化突擊兵，宛如一群地獄惡鬼，自破碎的穹頂索降而下！

沈天成那張原本斯文的臉上布滿了猙獰扭曲的刀痕，眼神瘋狂至極：

「哈哈哈……小雜種們！多虧你們替我啟動了透鏡，打開了通往地心的升降機！」

「沈董事長，你的對手是我！！」

一聲雄渾無比的怒吼在大廳中炸響！

只見白鬍子老莫里斯猛地抓起一把重達三十公斤的重型磁暴干擾扳手，以泰山壓頂之勢狠狠橫掃而出，一記重擊當場將兩名衝在最前方的生化兵砸得吐血倒飛！

隨後，老莫里斯猛地用肩膀撞上了升降機外的全封閉重型防爆安全閥，一把將升降機的艙門死死鎖定！

「莫里斯爺爺！！」嵐撲在厚重的防彈觀察窗前，淚流滿面地拼命拍打著玻璃。

「嵐丫頭！誠浩！聽我說！」

老莫里斯背靠著升降機門，擦掉嘴角溢出的鮮血，回頭隔著玻璃對著孩子們露出了三十年來最欣慰、最豪邁的燦爛笑容：

「三十年前，我和遠山、邱校長約定過……這座燈塔，由我來守護！」

「你們的戰場在下面！去救遠山！去拔掉那七根該死的地震針！！」

「莫里斯爺爺！！不要啊！！」誠浩拼命砸著艙門。

老莫里斯沒有再回頭，他一把扯斷了升降機頂部的主控信號線，右手死死拉下了那根刻著骷髏標記的**「緊急極限俯衝下墜桿」**！

「地心大門——給我開！！」

「轟隆隆隆————！！」

沉重無比的鈦合金升降機，在重力加速與超導磁懸浮的雙重推動下，如同一顆脫膛而出的流星，帶著撕裂耳膜的狂暴風嘯，朝著黑暗無底的三千公尺深海地心斷裂層，轟然向下極速墜落！

在觀察窗最後的視野裡，老莫里斯揮舞著巨大的扳手，與狂暴撲上來的黑潮士兵戰作一團，金色的光華與刺目的電弧在大廳內轟然引爆……

升降機儀表盤上的速度指針瘋狂飆升：

> `[當前下墜速度：-55 m/s！]`  
> `[深度：-500m……-1200m……-2400m……]`  
> `[距離地熱熔岩大廳剩餘：600米！]`  
> `[距第七地震針引爆超級海嘯剩餘：1小時45分！]`

地心終極決戰，拉開帷幕！
