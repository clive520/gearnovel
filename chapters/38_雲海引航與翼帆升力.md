# 第六章：雲海引航與翼帆升力

## 一、破曉啟航與晨曦飛舟

清晨五點二十分，當第一縷淡金色的朝霞抹平了琉光星港東側起伏的雲海時，晨光堂通往後港浮動碼頭的木棧道上，已然響起了急促而輕盈的腳步聲。

晨風帶著萬米高空特有的冷冽與潮濕，吹動著女孩們額前的碎髮。

「快！星耀機械大賽的複賽檢錄時間是早晨七點整！」十三歲的學徒少女<u>采婭玆</u>反背著雙肩工具箱，雙手小心翼翼地抱著那只裝有「晨曦一號」高頻機芯的防震黑金圓盒，腳步飛快地奔向碼頭邊緣。

緊隨其後的是跳級天才少女<u>林漪姉</u>。她穿著一件銀白色的防風引航風衣，金屬細框眼鏡的鏡片上不斷閃爍著微縮的全息氣象圖層：「星耀大賽的複賽賽場設在懸浮於萬米平流層的『星輝浮島』上。從舊城區到浮島，正常軌道纜車需要兩個半小時，但因為昨夜監察處的管道事故，整條南線公用軌道已經全線癱瘓！」

「那不是意外事故，是<u>雷諾</u>故意切斷了舊城區通往浮島的所有常規航線！」走在最前面的少年<u>罧貁銁</u>停下腳步，轉過身來。他身穿一套深海藍與星光銀交織的引航員制服，修長挺拔的身影在晨光中顯得格外可靠。

在<u>罧貁銁</u>身後的浮動泊位上，正靜靜繫泊著一艘造型極為獨特的小型雙體風帆艇——「追光者號」。

那不是普通的木質小艇，而是一艘由高強度碳纖維桁架、記憶鈦合金骨架與多層複合防撕裂翼帆打造的超輕型滑翔風帆艇。兩側船體猶如兩柄磨礪得極薄的柳葉飛刀，而在甲板上方，赫然矗立著一具足足有四米高的半硬質多段可變彎度「機械翼帆」。

「嗶啵——！風速每秒六點二米，迎角良好！」機械萌狐<u>露露</u>輕盈地躍上了艇首的黃銅平衡桿，兩隻折耳「刷」地張開，尾巴末端的微型皮托管風速感測器在晨風中滴溜溜高速旋轉。

「這就是你的船？」<u>林漪姉</u>仰頭注視著那具結構極其精密的複合翼帆，清冷的眼眸中不由自主地閃過一絲讚賞，「這不是傳統的軟質布帆……這分明是具備非對稱弧度截面的超臨界空氣動力學硬質翼面！」

「妳的眼力依舊這麼犀利，<u>林漪姉</u>。」<u>罧貁銁</u>爽朗地一笑，向兩位女孩伸出手，將她們穩穩拉上了甲板，「這是我和師傅花了三年時間改裝的深空引航艇。如果走常規航道，我們必定會被<u>雷諾</u>的巡邏艇攔截；但如果我們直接切入『黑峽大裂谷』的上升熱氣流區，迎風爬升，只需四十分鐘就能直插平流層浮島！」

「黑峽大裂谷？！」<u>采婭玆</u>抱緊了懷裡的機芯盒子，倒吸了一口涼氣，「老工匠們常說，那裡的雲海深不見底，兩側懸崖間常年盤踞著撕碎一切的剪變風暴與雷暴渦流，連大型蒸汽貨輪都不敢輕易涉足！」

「常規動力船害怕亂流，是因為它們笨重，只能靠蠻力對抗風阻；」<u>罧貁銁</u>走到舵輪前，修長有力的雙手握緊了主控操縱桿，眼神明亮如晨星，「但只要我們懂得風的語言，狂暴的亂流……就會成為送我們直上雲霄的最強翅膀！」

「解開繫泊纜繩！」<u>罧貁銁</u>一聲清越的長喝，「追光者號，啟航！」

「嗡——！」

隨著高壓氣動卡榫彈開，追光者號宛如離弦之箭般滑出泊位，雙體滑板破開翻滾的金色朝霧，朝著深邃莫測的萬米雲海峽谷疾馳而去！

## 二、黑峽裂谷與白努利升力方程式

不到十分鐘，追光者號便徹底脫離了星港外圍的平靜空域，穿入了兩座高達數千米的漆黑玄武岩斷崖之間。

這裡正是惡名昭彰的「黑峽裂谷」。深不見底的萬丈深淵中湧動著鉛灰色的厚重雲浪，高空冷空氣與地底地熱蒸汽在此交匯，形成了一股股狂暴無比的上升氣旋。

「呼呼呼————轟轟！」

狂風咆哮著抽打在翼帆上，整艘小艇在百米高空中劇烈顛簸，船身兩側的碳纖維翼板發出緊繃的嗡鳴！

<u>采婭玆</u>緊緊抓住船舷邊緣的防滑扶手，狂風吹得她幾乎睜不開眼。但即便在這樣的顛簸中，她的另一隻手依然如鐵鉗般護著懷裡的機芯盒，身體自然而然地隨著小艇的起伏調節著重心。

「風速正在暴漲！相對迎風航速達到每小時七十二公里（20 m/s）！」<u>林漪姉</u>背靠著桅杆基座，單手點擊手環，在狂風中投射出一道透明的流體力學向量分析面，大聲喊道：

「<u>罧貁銁</u>！你這具翼帆的氣動原理，正是古典流體力學的『白努利定律（Bernoulli's Principle）』對吧！」

「沒錯！」少年在舵輪前迎風傲立，黑髮隨風狂舞，眼中滿是自信的神采，「這具翼帆不是平板，它的上表面是凸起的光滑弧線，下表面是平直的凹面！」

<u>林漪姉</u>點頭接過話頭，清脆的聲音在風暴中清晰無比：

「根據連續性方程與能量守恆定律，氣流在流經翼帆截面時，被帆面前緣分割為上下兩股：

$$P_1 + \frac{1}{2}\rho v_1^2 = P_2 + \frac{1}{2}\rho v_2^2 = \text{常數}$$

流經上翼面凸起的空氣路程更長、流速 $v_{\text{upper}}$ 更快；流經下表面平坦處的空氣流速 $v_{\text{lower}}$ 較慢！」

「流速快的地方，靜壓強反而變小！」<u>采婭玆</u>眼睛一亮，大聲喊道，「上表面壓強 $P_{\text{upper}}$ 小於下表面壓強 $P_{\text{lower}}$，所以空氣在翼帆兩側產生了一股向上、向前的巨大壓力差！」

「這就是空氣動力學總升力公式！」<u>林漪姉</u>在光幕上飛快標注出升力方程：

$$L = \frac{1}{2} C_L \rho v^2 S$$

「其中 $C_L$ 是升力係數，$\rho$ 是雲海大氣密度，$v$ 是迎風相對速度，$S$ 是翼帆投影面積！只要我們維持足夠的前進風速，這股純粹的空氣動力學升力就能直接抵消全船重力，讓我們在雲海狂風中凌空滑翔！」

「抓穩了！現在我們要藉助第一道熱氣旋加速爬升！」<u>罧貁銁</u>雙手猛然下壓操縱桿，腳下踩下偏航舵踏板！

「嘩啦——！」

追光者號的半硬質翼帆在氣動伺服馬達的驅動下，瞬間完成了優雅的弧度扭轉。流經帆面的氣流爆發出高亢的呼嘯，整艘雙體飛舟在狂暴的峽谷風暴中如同一頭昂首展翅的信天翁，貼著筆直險峻的黑色崖壁拔地而起，以超過六十度的驚人仰角直衝雲霄！

## 三、鐵甲巡洋艦的截擊與失速危機

「成功越過第一裂谷段！高度四千八百米！」<u>采婭玆</u>看著舷窗外飛速下墜的黑色岩峰，興奮地喊道。

然而，還沒等三人鬆一口氣，前方的雲海濃霧中突然亮起了四盞刺眼的猩紅色大功率探照燈！

「轟隆隆隆————！！」

沉悶如雷的高壓鍋爐轟鳴聲自雲霧深處暴烈傳來。只見一艘足足有八十米長、通體覆蓋著重型鉚釘黑鐵裝甲的龐然大物，宛如一頭自深海浮起的鋼鐵巨獸，蠻橫無比地橫亙在裂谷唯一的向上出口通道前！

那是星港治安監察處的旗艦——「鐵手號」重型蒸汽巡邏巡洋艦！

在巡洋艦高聳的裝甲艦橋露台上，督察官<u>雷諾</u>迎風佇立，手中拿著大功率擴音終端，冰冷輕蔑的聲音穿透風雨在峽谷間回盪：

「<u>采婭玆</u>、<u>林漪姉</u>！你們果然想靠這艘破風帆偷渡去浮島！我以星港最高防衛委員會的名義通知你們，黑峽航道已被列為軍事管制禁區，立刻降下翼帆接受扣押，否則我們將啟動高壓蒸汽水炮將你們擊墜！」

話音未落，鐵手號舷側的四門高壓蒸汽防暴重炮已然轉動炮口，黑洞洞的炮膛鎖定了輕薄的追光者號！

「休想阻擋我們！」<u>采婭玆</u>挺身走到船頭，毫不畏懼地大喊，「星耀大賽是全星港公信的榮耀殿堂，你無權剝奪工匠與學者的參賽資格！」

「權力？在星港，蒸汽與鐵甲就是唯一的真理！」<u>雷諾</u>獰笑一聲，猛然下揮手臂，「開炮！給我打碎他們的帆面！」

「轟！轟！轟！轟！」

四道直徑超過半米、溫度高達一百五十度的白熾高壓蒸汽射流如狂暴的白龍般自炮管中噴湧而出，帶著撕裂空氣的尖嘯橫掃而來！

「抓緊！我們要大角度急轉規避！」<u>罧貁銁</u>眼神如電，雙手猛力扭轉舵輪！

追光者號在千鈞一髮之際以貼近水平面的極限傾角向左橫滑，熾熱的蒸汽柱擦著翼帆頂端呼嘯而過，將幾縷帆繩瞬間燙得焦黑！

然而，為了躲避後續連綿不絕的炮火，<u>罧貁銁</u>不得不將翼帆的迎角不斷向上拉大，企圖藉助更陡峭的仰角強行翻越鐵手號的艦頂！

十四度……十六度……十八度！

就在攻角跨過十六度的瞬間，小艇上方的氣流聲突然變了！

原本順滑流暢、如絲綢般貼合翼面的呼嘯聲，在零點一秒內變成了如同猛獸咆哮般的混沌雜音！整艘小艇猛地劇烈抖動起來，原本澎湃向上的升力彷彿在瞬間被抽乾，艇首猛然向下一沉，朝著下方萬丈深淵急速墜落！

「警告！警告！邊界層氣流完全剝離！升力驟降百分之七十！」全息手環上的光幕瞬間染成了猩紅色，<u>林漪姉</u>失聲疾呼：「<u>罧貁銁</u>！攻角太大超越了十六度臨界點！翼帆進入了『空氣動力學失速（Aerodynamic Stall）』！」

## 四、邊界層分離與可變彎度解法

「失速？！怎麼會這樣？迎角越大，推力不是應該越強嗎？」<u>采婭玆</u>在急速下墜的失重感中大聲問道，狂風將她的衣衫吹得獵獵作響。

「那是常人的直覺誤區！」<u>林漪姉</u>一手死死固定在桅杆扶手上，另一手在光幕上調出了翼截面的微觀氣流湍流模擬：

「在適度攻角下（$\alpha < 14^\circ$），氣流能順滑地貼合著翼面上表面流動；但當攻角 $\alpha$ 超越了『臨界失速攻角 $\alpha_{\text{crit}}$』，上翼面的逆壓梯度過大，空氣分子根本無法克服阻力轉彎，整個邊界層會在帆面前端瞬間剝離脫落！」

「剝離後的後方，會形成巨大的負壓紊流渦旋！」<u>林漪姉</u>指著光幕上那團混亂的紅色漩渦，「渦流非但無法提供吸力，反而會產生巨大的壓差阻力，徹底摧毀白努利壓強差！」

「我們正在以每秒三十米的速度向深淵墜落！距離谷底只有八百米了！」<u>露露</u>兩隻金屬耳朵發出刺耳的警報，雙眼中的測距雷射在地底岩礁上瘋狂跳動。

上方，鐵手號的蒸汽主炮再次開始蓄壓，白色的蒸氣在炮口凝聚，<u>雷諾</u>那得意的狂笑聲隱隱從雲海上方傳來。

「別慌！我們還有最後的底牌！」在生死存亡的千鈞一髮之際，少年引航員<u>罧貁銁</u>的臉上沒有絲毫絕望，只有孤注一擲的冷靜與魄力。

「<u>采婭玆</u>！<u>林漪姉</u>！聽我的口令！」<u>罧貁銁</u>雙手反扣住舵輪下方的兩個隱藏黃銅拉環，「追光者號的翼帆是三段式鉸接骨架！我們不能單純推拉仰角，我們必須改變它的『翼型彎度（Camber）』與前緣縫翼！」

「前緣縫翼與後緣襟翼？！」身為機械工匠的<u>采婭玆</u>瞬間心領神會，「你想透過改變翼帆的中弧線幾何形狀，延遲氣流剝離！」

「沒錯！當前緣縫翼下傾六度時，它會在前緣形成一條狹長的加速導流縫隙，把下翼面的高壓氣流噴射到上表面，給即將剝離的邊界層注入動能！」<u>林漪姉</u>指尖如飛，在手環上瞬間解算出了最優彎度參數矩陣：

「解算完成！

幾何攻角收斂至最優昇阻比：$\alpha = 11.5^\circ$！
前緣加速導流隙寬度：四點二毫米！
後緣柔性襟翼下偏：二十二度！

這樣能將臨界失速攻角從十六度大幅推遲到二十四度，昇阻比提升三點二倍！」

「<u>采婭玆</u>，右側副翼機械絞盤！」<u>罧貁銁</u>大喊。

「交給我！」<u>采婭玆</u>從工具包中猛然抽出一把長柄黃銅棘輪扳手，毫不猶豫地撲向右舷的調節絞盤，雙手青筋暴起，憑藉著工匠極限的爆發力「咔咔咔」連扳七扣，將前緣導流縫翼死死卡死在四點二毫米的理論刻度線上！

「左舷襟翼伺服同步到位！」<u>林漪姉</u>精準按下手環上的電磁指令！

「就是現在——追光者號，破風滑翔吧！」<u>罧貁銁</u>將舵輪推至極限！

## 五、破譯 GLIDE 密碼，穿透萬米雷暴

「嗡——————！！」

在距離谷底礁石僅剩不到三百米的生死瞬間，奇蹟轟然爆發！

經過重新塑形的三段式可變彎度翼帆，宛如一柄重新開刃的神聖光刃，將原本紊亂崩潰的氣流瞬間馴服！

流經前緣導流縫隙的高速氣流如同一道道無形的梳子，將即將脫離的邊界層死死按壓在上翼面上；原本暴烈的紅色渦旋在千分之一秒內消散殆盡，取而代之的是平滑無比的深藍色高速流線！

白努利壓強差瞬間暴增！澎湃至極的向上升力如同一隻托舉蒼穹的巨掌，硬生生將急速墜落的追光者號從小艇墜毀的邊緣拽了回來！

「轟——！」

小艇在谷底上方兩百米處完成了一道不可思議的平滑超低空仰角改出，隨後借著峽谷深處咆哮的熱氣流，以近乎兩倍音速的滑翔加速度筆直向上狂飆！

此時，鐵手號蓄力已久的四門高壓蒸汽主炮終於轟然齊射！

然而，四道毀滅性的白色蒸汽光柱全數狠狠打在了追光者號剛剛墜落的空坐標上，在堅硬的玄武岩崖壁上轟出四個巨大的熔岩焦坑，卻連小艇的一片尾羽都沒能碰到！

「可惡！他們怎麼可能在失速狀態下改出？！」艦橋上的督察官<u>雷諾</u>眼珠暴凸，氣急敗壞地拍打著指揮台，「全速追擊！給我撞碎他們！」

「已經太遲了，<u>雷諾</u>督察官！」

高空之上，少年<u>罧貁銁</u>瀟灑地一拉主帆索，追光者號如同一隻翱翔九天的獵鷹，輕巧無比地掠過鐵手號高聳的艦橋頂端，強勁的翼尖氣流甚至將艦頂的監察處旗幟硬生生扯斷！

下一秒，追光者號破開了最後一層翻滾著雷電的黑峽雷暴雲！

「轟隆——咔嚓！」

一道刺目的天雷在小艇舷側千米處炸裂，但艇頂的記憶琉璃翼帆卻將雷暴空氣中的高密度電場轉化為一道道流動的青金光芒，沿著翼面流線優雅滑行。

穿透雷雲的瞬間，整個世界豁然開朗！

萬米高空的平流層之上，沒有陰霾，沒有暴雨，只有無邊無際如純白棉絮般平整的雲海，以及浩瀚純淨、泛著深邃紫藍色的晴朗天穹！

在萬里雲海的中央，一座閃爍著萬千璀璨琉璃光芒的空中浮島——「星輝浮島」，在金色朝陽的沐浴下赫然聳立！那是星耀機械大賽的複賽聖殿！

追光者號以最優昇阻比在萬米高空的純淨平流層中優雅滑翔，空氣阻力小得微不可察，整艘艇身平穩得如同在鏡面上滑行。

就在這時，翼帆中央的氣動感測液晶屏上，那組記錄著最優彎度攻角的氣動坐標序號，正伴隨著 A1Z26 密碼學模組的共鳴急速閃爍：

```
07 - 12 - 09 - 04 - 05
```

「快看！氣動平衡代碼解密了！」<u>采婭玆</u>興奮地指著螢幕。

金色的光斑在晨光中凝聚，逐字逐句還原出清晰的英文明文：

* **07** ➜ 第七個字母：**G**
* **12** ➜ 第十二個字母：**L**
* **09** ➜ 第九個字母：**I**
* **04** ➜ 第四個字母：**D**
* **05** ➜ 第五個字母：**E**

**【 G - L - I - D - E 】 ➜ GLIDE（迎風滑翔 / 破空翱翔）！**

「GLIDE……滑翔！」<u>林漪姉</u>推了推眼鏡，嘴角勾起一抹極其動人的弧度，「迎風展翼，不借蠻力，唯有順應物理學的規律，才能在最深邃的亂流中自由滑翔。」

「這就是引航的意義所在。」<u>罧貁銁</u>轉過頭，迎著璀璨的朝霞注視著兩位少女，英俊的臉上浮現出無比溫柔的微笑，「無論前方的航道有多少迷霧與風暴，只要有你們的智慧與信念在，我就能為你們引領出通往光芒的正確軌道。」

「嗶啵——！到達浮島登陸港！用時三十八分鐘！」<u>露露</u>歡快地在甲板上打了個滾，抖了抖毛茸茸的耳朵。

清晨六點五十八分，追光者號在星輝浮島的漢白玉泊位上平穩滑行靠岸。檢錄處的裁判長手捧著計時器，目瞪口呆地看著這艘迎著朝陽破空而至的奇蹟風帆艇。

<u>采婭玆</u>高高捧起懷中完好無損的晨曦一號機芯，與身旁的<u>林漪姉</u>和<u>罧貁銁</u>並肩踏上了星耀大賽複賽的金色階梯。

天穹之上，晨曦普照；屬於追光者們的真正傳奇，已然破風翱翔！
