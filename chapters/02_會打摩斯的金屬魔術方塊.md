# 第二章：會打摩斯的金屬魔術方塊

## 一、走廊上的生死追逐

三台原本笨重圓滾的清潔巡邏機器人，此刻像變成了三隻飢餓的金屬獵犬。

它們眼部的LED螢幕閃爍著刺目的猩紅感嘆號，底部橡膠履帶在光滑的米黃色瓷磚地上瘋狂打滑，隨後伴隨著「刺啦——」一聲尖銳的摩擦巨響，猛然彈出兩根足足有一米長的銀灰色機械抓捕臂！

「警告：非法觀察者！立刻停止行動，接受記憶校準！」

冰冷無情的機械廣播在走廊裡迴盪。

教室門口，將江還舉著那瓶鮮奶，嘴巴張得大大的，整個人徹底嚇傻了：「誠……誠浩？這幾台掃地機器人怎麼瘋了？它們怎麼長出鉗子來了？！」

「趴下！」

誠浩根本來不及多作解釋，整個人如同一頭敏捷的獵豹貼地飛撲過去！

他的肩膀狠狠撞在將江的腰際，兩人一起滾進了教室門口。就在千鈞一髮之際，將江手裡那瓶「智慧健腦鮮乳」脫手飛出，重重砸在一台機器人的鋼鐵底盤上，「啪嚓」一聲粉碎！

乳白色的液體濺了一地。

透過額頭上的幽靈護目鏡，誠浩看得清清楚楚——地上的牛奶接觸到空氣的瞬間，那些微小的金屬螢光點竟然像有生命的納米蟲一樣劇烈蠕動，隨後化作縷縷極淡的紫煙消散在空氣中。

「我的天……」將江摔得屁股生疼，看著滿地的碎片直揉眼睛。

「沒時間發呆了！」

這時，一隻纖細卻有力的手猛地抓住了誠浩的衣領。

是葉旖緁！

只見這位平日裡優雅冷靜的學霸班長，不知何時已經抄起了走廊消防栓旁邊的一把大號乾粉滅火器。她毫不猶豫地拔掉保險銷，雙手緊握噴管，對準衝在最前面的那台清潔機器人的光學鏡頭，狠狠按下了壓把！

「噗——呼——！！」

濃密刺鼻的白色乾粉如同暴風雪般呼嘯而出，劈頭蓋臉地將領頭的機器人噴了個正著！

乾粉瞬間糊滿了機器人的光學感測器。猩紅色的電子眼在一片白茫茫中瘋狂閃爍，發出刺耳的系統報錯聲：

`[光學鏡頭遮蔽度 98%……啟動聲納輔助……]`

「幹得漂亮，旖緁！」誠浩大喊一聲，隨即從口袋裡抽出他的瑞士刀螺絲筆，按動側邊的紅色卡榫。

「喀噠！」一根細長的平頭導電金屬探針彈了出來。

誠浩趁著機器人原地轉圈重啟系統的兩秒空隙，一個滑鏟鑽到了機器人身後，準確無誤地將金屬探針狠狠刺入了機器人後頸處一條裸露的接地電線接口！

「滋滋滋——劈啪！」

一串耀眼的藍白色電火花瞬間爆開。

那台重達六十公斤的清潔機器人渾身劇烈抽搐了一下，頭頂冒出一縷黑煙，機械臂軟綿綿地垂了下來，徹底癱瘓在地上。

「還剩兩台！」旖緁丟掉空滅火器，一把拉起誠浩，「全校的安保系統都被驚動了，走廊盡頭的防火鐵捲門正在降下！去哪裡？」

誠浩抬頭看去，只見走廊頂端的金屬鐵捲門正伴隨著刺耳的蜂鳴聲緩緩下壓。

「舊校舍！」誠浩當機立斷，指向走廊側邊那扇通往老校區的木質防火門，「去三樓那間廢棄的舊物理實驗室！快跑！」

## 二、塵封的舊實驗室

兩人推開生鏽的逃生通道小門，一路沿著狹窄昏暗的木質樓梯狂奔。

身後傳來另外兩台機器人履帶碾過樓梯的沉重撞擊聲，以及防火門被機械臂瘋狂撞擊的巨響。

鹿陽國小的舊校舍建於六十年前，據說是齒輪鎮第一代機械工程師們親手設計的。這裡的走廊鋪著老舊的柚木地板，空氣中瀰漫著機油、舊紙張與淡淡鐵鏽的味道。因為被列為危樓，平時根本沒有任何學生敢靠近。

「砰！」

誠浩反手將舊物理實驗室沉重的橡木大門重重甩上，順手拉下了兩道厚實的生鏽插銷。

門外傳來履帶急停與金屬掃描光束掠過門縫的微弱「嗡嗡」聲，但由於舊校舍全由厚重的紅磚與鉛板隔音層構成，門外的機器人似乎暫時失去了信號鎖定，在走廊裡漫無目的地徘徊。

實驗室內安靜得只能聽見兩人急促粗重的喘息聲。

正午微弱的陽光透過積滿灰塵的毛玻璃窗灑進來，空氣中無數塵埃在光柱中緩緩起舞。

「呼……呼……」旖緁扶著滿是灰塵的實驗台，推了推歪掉的金屬眼鏡，胸口劇烈起伏，「誠浩……剛才在走廊上，機器人發出的清除指令……鎖定的目標是你。這絕對不是單純的設備故障。」

「我知道。」誠浩撫摸著頭上的黃銅護目鏡，目光凝重，「是因為這副護目鏡。它能看見不該看見的代碼。那些把昨天『星期三』抹掉的人，不希望任何人看破他們的把戲。」

「那……你為什麼要帶我來這裡？」旖緁環顧四周。

這間實驗室堆滿了落滿蛛網的老式天平、手搖發電機、還有幾具用黃銅齒輪組裝的機械天文儀模型。

「因為我爺爺留給我的舊手冊裡，有一張泛黃的學校草圖。」誠浩走到實驗室最深處的一面老舊黑板前，「爺爺在手冊最後一頁寫著一句話：『如果你迷失在代碼的世界裡，去青木的根部，找尋金屬的心跳。』」

「青木的根部……」旖緁喃喃道，「鹿陽國小在四十年前改名前，原本的名字就叫『青木私塾』！」

「沒錯！」

誠浩蹲下身子，鑽到了講台下方最角落的暗處。

那裡放著一台早已報廢的舊式顯微鏡收納箱。誠浩用力將沉重的木箱挪開，地面上赫然出現了一塊由四顆巨大內六角螺絲固定的暗灰色鉛金屬暗格！

暗格表面覆蓋著厚厚的油泥，正中央嵌著一個極其精巧的旋轉密碼鎖盤。

## 三、齒輪與質數的謎題

「找到了！」誠浩興奮地喊道，連忙掏出螺絲筆擦掉表面的污垢。

鉛金屬板上沒有鑰匙孔，只有三個獨立的金屬刻度轉盤，每個轉盤上刻著數字 `0` 到 `9`。

而在轉盤上方，用工整的機械刻刀刻著三行泛著銅綠的謎題：

```
第一個數：十以內最大的質數。
第二個數：一打的一半，除以最小的合數。
第三個數：二進位數字「1001」所代表的十進位數值。
```

「三位數密碼鎖！」誠浩看著金屬板上的刻字，「這是我爺爺親手設計的防撬機關，如果連續輸入錯誤三次，裡面的自毀硫酸管就會融化所有東西！」

「別慌，交給我。」

旖緁蹲在暗格旁，眼神瞬间恢復了學霸專屬的冷靜與犀利。她盯著那三行刻字，大腦如同精密的超級電腦飛速運算。

「第一行：『十以內最大的質數』。」旖緁開口，聲音平穩清晰，「十以內的質數有 2、3、5、7。其中最大的是——**7**！」

誠浩點點頭，伸出手指，將第一個轉盤緩緩撥動。

「咔、咔、咔……」金屬卡簧發出悅耳的脆響，停在數字 **7** 上。

「第二行：『一打的一半，除以最小的合數』。」旖緁接著說，「一打是 12，一半就是 6。最小的合數不是 1，不是 2，不是 3，而是 4！等等……6 除以 4 不是整數！」

誠浩的心臟猛地一跳：「不是整數？難道是餘數？還是小數點？」

「冷靜，再讀一遍字面邏輯！」旖緁眉頭緊鎖，死死盯著那行刻字，「『一打的一半』……如果不是指數量呢？如果是指時鐘指針的一打（12小時）？不對……」

突然，旖緁眼睛一亮：「看英文刻痕！在『合數』兩個字下方，有一道極淡的英文縮寫：`div`！在電腦程式語言裡，`div` 代表的是『整數除法，只取商數，捨去餘數』！6 除以 4，商數是 1，餘數是 2！所以只取商數——**1**！」

「好！」誠浩深吸一口氣，將第二個轉盤精準地撥到了數字 **1**。

「最後一個數：二進位數字『1001』。」旖緁嘴角微微揚起，露出一抹自信的微笑，「這對我們來說太簡單了。二進位從右往左權重分別是 1、2、4、8。『1001』就是：1 個 8，加 0 個 4，加 0 個 2，加 1 個 1。8 ＋ 1 等於——**9**！」

「密碼是：**7 - 1 - 9**！」

誠浩屏住呼吸，手指輕輕搭在第三個轉盤上，輕輕一推。

「喀噠！」

數字 **9** 歸位的剎那，鉛金屬暗格深處傳來了一陣極其複雜、連鎖反應般的金屬齒輪咬合聲！

「滋——嗡——」

一陣清脆的氣壓釋放聲響起，厚重的鉛板蓋子緩緩向上彈開了一道兩指寬的縫隙。

---

## 四、甦醒的摺紙柴犬

誠浩與旖緁小心翼翼地合力掀開鉛板蓋。

暗格裡面鋪著厚厚的紅色防震絲絨。而在絲絨的正中央，靜靜地躺著一枚巴掌大小的金屬立方體。

那立方體通體泛著深邃的啞光銀色，外表面並不是光滑平整的，而是由數百片薄如蟬翼、交錯折疊的記憶合金薄片緊密咬合在一起，看起來就像一個精密無比的六面魔術方塊。

「這就是……爺爺留下的東西？」誠浩伸出手，將那枚沉甸甸的金屬方塊捧在手心。

方塊冰涼刺骨。

但就在誠浩戴著護目鏡靠近的一瞬間，護目鏡鏡片上那圈微型光譜濾鏡忽然發出了一聲極輕的微鳴。

護目鏡的鏡框與金屬方塊之間，似乎產生了一種看不見的磁場共振！

「嗡——」

金屬方塊正中央的一條微細縫隙中，突然亮起了一道清澈純淨的幽藍色光芒！

緊接著，不可思議的一幕發生了——

「喀噠！喀噠！喀噠！」

一連串清脆如鐘錶齒輪跳動的機械響聲中，金屬方塊上的數百片合金薄片竟然如同活過來一般，優雅而繁複地向外層層展開！

它的四角向外延伸，折疊出四條線條流暢的機械小短腿；金屬頂端翻轉升起，重組出一顆輪廓分明的柴犬腦袋，兩隻三角形的小耳朵敏銳地豎立起來；而在它的身後，一條由七節金屬環扣串連而成的小尾巴歡快地彈了出來！

一隻由高科技記憶合金折疊而成的機械摺紙柴犬，活靈活現地站在了誠浩的手掌心上！

它的兩隻眼睛是兩枚極小、極精密的幽藍色微型光學鏡頭，此時正微微轉動著，發出輕微的對焦聲。

「哇……」旖緁忍不住輕呼出聲，眼睛裡滿是震撼，「這簡直是……機械工藝的奇蹟！」

機械小狗歪了歪腦袋，藍色鏡頭在誠浩臉上的護目鏡上停留了兩秒，似乎完成了虹膜與設備識別。

隨後，它歡快地從誠浩手掌上跳到了滿是灰塵的實驗台上，小鐵爪在木頭桌面上發出「噠噠噠」的清脆聲響。

「嗶——啵！」

小狗張開金屬小嘴，發出了一聲奶聲奶氣的電子音效。

在它的金屬項圈上，一行極小的激光刻字清晰可見：

`MODEL: PICO-001 (皮可)`

「你叫皮可？」誠浩驚喜地看著它。

皮可甩了甩小腦袋，似乎在表達肯定。但下一秒，它的藍色雙眼突然驟變為警惕的橙黃色！

它的小鼻子在空氣中使勁嗅了嗅——那是它隱藏在高靈敏度鼻頭內的光譜與信號分析儀正在全速運轉。

「嗒！嗒！嗒！——嗒嗒嗒！——嗒！嗒！嗒！」

皮可的金屬尾巴突然高高豎起，開始以極快的頻率，重重敲擊在實驗台的一塊鋼質鐵板上！

「他在敲東西？」誠浩一愣。

「等等！別出聲！」旖緁猛地一把抓緊了黑皮筆記本，耳朵豎了起來，「三短、三長、三短……這是摩斯密碼！」

## 五、地下二樓的紅色座標

旖緁手裡的鋼筆幾乎劃破紙面：

「`···` 是 **S**！」  
「`---` 是 **O**！」  
「`···` 是 **S**！」  
「它在發求救訊號？不對，後面還有！」

皮可的尾巴敲擊節奏驟然變換，敲擊聲變得急促而連貫：

「嗒嗒——嗒——（`··-` 是 **U**）」  
「嗒——嗒嗒（`-··` 是 **D**）」  
「嗒——（`-` 是 **T**）」  
「嗒嗒嗒嗒（`····` 是 **H**）」  
「嗒（`·` 是 **E**）」  
「嗒——嗒（`--` 是 **M**）」  
「嗒嗒（`··` 是 **I**）」  
「嗒——嗒（`--` 是 **M**）」  
「嗒嗒嗒（`···` 是 **S**）」  
「嗒嗒——（`··-` 是 **U**）」  
「嗒——嗒（`--` 是 **M**）」

「**U - D - T - H - E - M - I - M - S - U - M**？」旖緁一邊拼讀，眉頭越皺越緊，「這根本不是英文單詞啊！難道是隨機亂碼？」

「不，不是亂碼！」誠浩盯著皮可那雙緊張閃爍的眼睛，腦海中靈光一閃，「旖緁，把字母倒過來讀！或者……凱撒位移？」

「等等！」旖緁的指尖在紙面上猛地一頓，倒抽一口冷氣，「將每個字母向前移位一位！U 前面是 T，D 前面是 C……不對，看單詞的分隔——」

旖緁飛快地用斜線切開：

`UD` ➡️ **UNDER**（地下）  
`THE` ➡️ **THE**（那個）  
`M-U-S-E-U-M` ➡️ **鐘樓地底博物館**！

「**UNDER THE MUSEUM**！它說秘密在學校老鐘樓地下的舊校史博物館裡！」

話音剛落，只見皮可胸口的一塊金屬板「啪」地彈開，一束強烈的高清全息光束從它胸膛投射到半空中！

那是一張鹿陽國小立體的三維地下透視圖！

在整座校舍的三維模型中，地下一樓是平平無奇的鍋爐房與庫房。但在地下一樓的正下方，赫然存在著一個巨大的、全校任何建築圖紙上都從未標記過的龐大空間！

那個空間閃爍著觸目驚心的血紅色倒數計時光芒，正中央清晰地標註著四個燃燒著紅光的數字：

> `[ZONE: UNDERGROUND B2]`  
> `[ROOM 404: 核心中央處理室]`  
> `[全鎮記憶永久重置倒數：47 小時 59 分 59 秒]`

「地下二樓……404 室真的存在！」誠浩的心臟狂跳不已。

然而，還沒等兩人喘過氣來，實驗室厚重的橡木大門突然傳來「咚！！」的一聲沉悶巨響！

門縫下方，一束刺眼的藍色高溫切割激光「嗤嗤」冒著火星，正以恐怖的速度自上而下，將兩道生鏽的鐵插銷齊齊切斷！

門外，傳來了一個經過機械變調、冰冷徹骨的聲音：

「找到你們了，六年一班的小老鼠。」
