# 第十五章：邁克生干涉儀與雙星測徑

## 一、伴星微震與光學極限

上午十一點三十分，天極雙星天象台頂部的微風帶著萬米高空的凜冽與純淨，吹拂著青銅穹頂下那一排排精密的觀測儀表。

在第十四章成功以三級色散稜鏡陣列分離出十二公尺寬的壯麗彩虹光譜、精確提取出雙星引力共振本徵頻率後，整座星港天樞科學院的中央數據庫中，三萬噸反重力晶體的劇烈諧波震盪終於得到了根本性的遏制。然而，一場更為隱秘而兇險的深空物理危機，卻悄然在天穹最深處浮現。

全息主控台前，天象台老守護者<u>莫拉長老</u>將光學望遠鏡的倍率推向了極限的一萬二千倍。屏幕中央，天極藍巨星 A 身旁那顆小巧而璀璨的伴星——金矮星 B，正處於五百年來最靠近主星的近日點引力撕裂區。

強大的潮汐引力差如同一隻無形的神之巨手，在金矮星 B 的超高密度金屬星體表面引發了極其劇烈的「非徑向星震脈動（Asteroseismic Pulsation）」。伴星內部數億噸高溫等離子流在高頻共振下瘋狂湧動，整顆恆星正在以每秒數十次的頻率發生微米級的週期性劇烈脹縮！

「滋滋……呼叫天象台！呼叫<u>林漪姉</u>與<u>采婭玆</u>！」

通訊終端中再次傳來天樞科學院院長<u>林嚴</u>凝重得近乎滴水的聲音。螢幕上，院長身後的全息城市微積分引力剖面圖上，代表星港懸浮底座的三萬噸晶體矩陣，正被一圈圈微小卻致命的高頻引力剪切波紋所困擾：

「我們剛剛收到最新空間引力回饋！金矮星 B 的星震脈動在大氣層外側激發出了微重力剪應力！如果我們不能在半小時內測量出金矮星 B 的真實物理直徑、角直徑（Angular Diameter），以及它表面星震位移的精確微米振幅，我們就無法在全城反重力陣列中寫入精確的『引力梯度補償向量』！一旦雙星在正午十二點整完全對齊，引力剪應力將在瞬間撕裂全城三千條懸浮主光軌！」

「測量恆星的真實角直徑？」十三歲的學徒少女<u>采婭玆</u>快步走到主望遠鏡的主光學接口前，深琥珀色的眼眸中閃爍著工匠特有的敏銳光芒，「可是長老，主望遠鏡的物鏡直徑已經高達兩公尺，難道還看不清伴星的邊緣嗎？」

「看不清，孩子，完全看不清！」<u>莫拉長老</u>深深嘆息，神情中滿是科學家的無奈與敬畏。老人指著光學屏幕上那團邊緣模糊、被無數明暗同心衍射光環包裹的微小光斑，「金矮星 B 距離我們足足有數光年之遙，它在天空中的真實視張角（角直徑）只有極其微小的幾毫角秒（Milliarcseconds）！這遠遠小於兩公尺口徑望遠鏡的光學繞射極限！」

「那是波動光學中不可逾越的物理高牆——『瑞利判據（Rayleigh Criterion）』！」站在一旁的跳級數學天才少女<u>林漪姉</u>推了推眼鏡，修長的雙手在全息計算板上飛速寫下一道經典的光學公式，清冷而犀利的聲音在大殿中響起：

```
【光學口徑繞射極限與瑞利判據】：

θ_min = 1.22 · (λ / D_tel)

• λ 為光波波長（取可見光中心波長 λ = 550 nm）；
• D_tel 為望遠鏡主物鏡口徑（D_tel = 2.0 m）；
• 計算可得望遠鏡理論最小角分辨率：
  θ_min = 1.22 × (550 × 10⁻⁹ m) / 2.0 m ≈ 3.35 × 10⁻⁷ rad ≈ 0.069 角秒（69 毫角秒）！
```

「看這個數字！」<u>林漪姉</u>眼眸深邃，語氣斬釘截鐵，「兩公尺口徑望遠鏡的最大極限極限分辨率是六十九毫角秒！而金矮星 B 的真實角直徑預測值不足五毫角秒！在光學成像中，伴星的影像完全縮成了一個不可分辨的『愛里斑（Airy Disk）』。無論你把目鏡放大多少倍，你看到的永遠只是一個被繞射波紋包圍的虛假光球，根本量不出它的真實邊界，更不可能測出它微米級的星震脈動！」

「也就是說，如果我們想看清它，就必須擁有一具直徑超過二十公尺的超巨型望遠鏡物鏡？」十四歲的首席引航少年<u>罧貁銁</u>倒吸了一口涼氣，望向天象台窗外的萬仞絕壁，「但在短短半小時內，世上根本不可能憑空鑄造出一面二十公尺直徑的透鏡！」

趴在工作台邊緣的機械小狐狸<u>露露</u>發出了一聲焦慮的輕鳴，銀白色的金屬耳朵垂了下來，長尾上的激光測距針在虛空光斑中無助地晃動。

「常規的透鏡成像確實不可能，」<u>采婭玆</u>撫摸著腰間的調音扳手，目光逐漸從凝重化為晨曦般的明澈，「但爺爺<u>采修誠</u>曾教過我：當機械的尺度達到極限時，工匠便不再觀察物體本身，而是去傾聽『波』在相遇時的心跳！」

「波在相遇時的心跳……」<u>林漪姉</u>猛然轉身，天才少女的雙眼中瞬間綻放出難以置信的耀目光芒，「對！是光波的相干性！我們要跳過幾何成像，直接啟動波動光學史上的至高神器——『邁克生干涉儀（Michelson Interferometer）』！」

## 二、邁克生干涉與光程差微積分

「如果我們不能把物鏡做大，我們就用光波干涉把兩束光分開！」

<u>林漪姉</u>手中的粉筆在天象台的黑板上風馳電掣般劃過，迅速勾勒出一套極其精妙、完全對稱的正交十字形光學系統。少女清澈明晰的嗓音在大殿中迴盪：

```
【邁克生干涉儀原理與分振幅干涉幾何模型】：

1. 光束分割（Beam Splitting）：
   一束平行相干光射入與光軸成 45° 夾角的「半透半反分束鏡（Beam Splitter, G₁）」：
   • 一半光強反射至上方動鏡 M₁（光路一，長度 d₁）；
   • 另一半光強透射至右方定鏡 M₂（光路二，長度 d₂）。

2. 垂直反射與重新疊加：
   動鏡 M₁ 與定鏡 M₂ 分別將光束沿原路反射回分束鏡 G₁，在相交點重新疊加，
   合成一束干涉光射向觀察屏（目鏡或探測器）。

3. 兩臂光程差（Optical Path Difference, OPD）：
   當動鏡 M₁ 與定鏡 M₂ 垂直時，兩束相干光在觀察屏處形成「等傾干涉（Haidinger Fringes）」同心圓環！
   中心光程差方程為：
   Δ = 2 · (d₁ - d₂) · cos(θ) ≡ 2d · cos(θ)

   • 干涉加強（亮紋條件）：Δ = 2d · cos(θ) = m · λ  （m 為干涉級數）；
   • 干涉減弱（暗紋條件）：Δ = 2d · cos(θ) = (m + 1/2) · λ！

4. 動鏡微米位移與條紋吞吐（Fringe Shift）：
   若動鏡 M₁ 沿軸線移動極微小的距離 Δd，光程差改變量為 2Δd！
   觀察屏中心湧出或縮入的干涉環數目 N 滿足精密微積分關係：
   N = 2 · Δd / λ  ⟹  Δd = N · (λ / 2)！
   （以 λ = 550 nm 計算，條紋每移動一環，動鏡位移僅為 275 奈米！
    亞奈米級微米位移無所遁形！）
```

「看這道條紋吞吐方程！」<u>林漪姉</u>激動地用筆尖圈出 $\Delta d = N \cdot (\lambda / 2)$，「如果我們把金矮星 B 的星震光波導入邁克生干涉儀，恆星表面哪怕發生一微米的脹縮，干涉環中心就會在千分之一秒內瘋狂吞吐近四個完整的明暗週期！這意味著我們能以奈米級的超級精度，即時鎖定星震的全部動態微擾！」

「但是，光有邁克生干涉儀還不夠，」站在一旁的<u>采婭玆</u>凝視著黑板上的光路圖，敏銳的工匠直覺立刻指出了光學結構中一個最隱蔽、最致命的瑕疵，「<u>林漪姉</u>，看分束鏡 G₁ 的玻璃基底！光線在反射向動鏡 M₁ 時，是從分束鏡前表面鍍膜反射的；而透射向定鏡 M₂ 的光線，卻整整穿透了分束鏡的玻璃厚度兩次！」

「天才的洞察力！」<u>林漪姉</u>眼中滿是敬佩，隨即在光路二中畫上了一塊平行玻璃板，「這就是白光干涉中最可怕的『介質非對稱色散色差』！如果不加處理，不同波長的光在玻璃中的折射率不同，會導致嚴重的附加色散光程差，中央白光干涉條紋將被徹底沖刷湮滅！因此，我們必須在光路二中插入一塊與分束鏡厚度、材質、折射率完全絕對相同的『色散補償板（Compensating Plate, G₂）』！」

「材質相同、厚度相同、且兩表面平面度嚴格平行的補償板……」<u>莫拉長老</u>倒吸一口涼氣，「這在光學冷加工中被稱為『孿生晶片』，公差要求小於二十奈米！星港庫存裡根本沒有現成的成對配件！」

「晨光堂的原料匣裡有！」<u>采婭玆</u>自信地微微一笑，從厚重帆布工具袋中小心翼翼地取出了一枚巴掌大小的天然零應力超純石英晶圓。

「而且，這還只是第一步，」少女轉頭看向窗外浩瀚的蒼穹，聲音清澈而堅定，「要想測出伴星金矮星 B 的幾毫角秒角直徑，我們還需要把邁克生干涉儀升級為傳奇的『邁克生恆星干涉儀（Michelson Stellar Interferometer）』！」

```
【邁克生恆星干涉儀角直徑消光模型】：

1. 外置超長基準線光學臂：
   在天象台外側架設兩具可沿導軌水平滑動的平面反射鏡（間距為基準線長度 D），
   將收集到的星光反射導入中央邁克生干涉儀。

2. 空間相干性與條紋可見度（Visibility）：
   圓形恆星圓盤（角直徑 θ）發出的光在兩鏡處產生微弱相位差。
   干涉條紋的對比度 V(D) 隨基準線 D 的增大而衰減：
   V(D) = (I_max - I_min) / (I_max + I_min) = | 2 · J₁(π · θ · D / λ) / (π · θ · D / λ) |

3. 第一零點消光條件（First Extinction Point）：
   當基準線長度拉伸至特定極限 D₀，干涉條紋對比度首次降為絕對零（條紋完全消失）！
   此時滿足貝索函數第一零點方程：
   π · θ · D₀ / λ = 3.8317
   ⟹  θ = 1.22 · (λ / D₀)！
```

「看最後這個方程！」<u>林漪姉</u>興奮得聲音發顫，「只要我們將兩側反射鏡的基準線 $D$ 拉開到二十四公尺，天象台的等效光學口徑就瞬間從兩公尺暴增到了二十四公尺！最小角分辨率將直接突破到四點五毫角秒！金矮星 B 的真實角直徑將在消光瞬間被一擊必中！」

「二十四公尺外展基準線……」少年<u>罧貁銁</u>挺起胸膛，一把拉下護目鏡，「天象台兩翼懸挑在三千公尺絕壁上的導軌，剛好全長二十四點五公尺！外展反射鏡的引導與定位，交給我和<u>露露</u>！」

## 三、晨光堂零應力分束鏡與柔性微調台

「分束鏡與補償板的孿生研磨，交給我！」

在天象台中央光學工坊內，<u>采婭玆</u>戴上了白棉手套與單眼六十倍珠寶微雕放大鏡。

少女取出的那塊超純天然石英晶圓，是晨光堂祖輩在深山寒潭中冷卻存放了四十年的零應力光學水晶。內部沒有任何內應力雙折射，是製作精密分束鏡與補償板的無上聖品。

「爺爺說過，研磨一對絕對平行的孿生干涉片，最忌諱單向受力。」<u>采婭玆</u>將石英晶圓夾在因瓦合金均勻三點式浮動夾具中，手握特製的金剛石微米線鋸，以每分鐘僅三毫米的極慢均速將晶圓垂直剖開成兩片厚度完全相同的石英薄片，「切削速度越慢，材料內部的晶格晶格畸變就越小。」

<u>采婭玆</u>在超平鑄鐵研磨盤上滴入三滴零點一微米的納米金剛石拋光液。少女雙手輕柔地按住兩片石英片，以大自然的黃金分割螺線軌跡，均勻施加零點八牛頓的垂直壓力，讓兩塊石英片在研磨盤上相互研磨。小狐狸<u>露露</u>伸出靈敏的金屬爪子，精準地握著一支氦氖激光干涉測厚儀，尾尖的紅外感測束實時打在晶片表面。

最後三次八字形交叉輕推完成！

「激光干涉牛頓環完全展開！平面度誤差小於二十五奈米（$\lambda/22$）！兩片石英片厚度差小於三奈米！完全對稱！」<u>林漪姉</u>忍不住激動地握緊了拳頭。

「分束鏡與補償板就位！現在是動鏡驅動核心——『壓電柔性四連桿移相台（PZT Flexure Stage）』！」

然而，通訊頻道中突然傳來了一陣狂暴的呼嘯風聲！

「天象台注意！外展滑軌終端遭遇側向狂風！」<u>罧貁銁</u>的聲音在對講機中斷續響起，「懸挑在懸崖外二十四公尺處的左側副鏡滑塊卡死了！導軌上的滾珠軸承被冰雹卡住了！」

## 四、雙翼高空外展基線與條紋消光

「滑塊卡死？那二十四公尺的長基準線就無法展開了！」天象台內，<u>莫拉長老</u>臉色驟變。
