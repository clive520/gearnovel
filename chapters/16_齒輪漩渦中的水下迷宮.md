# 第十六章：齒輪漩渦中的水下迷宮

## 一、阿基米德浮箱的生死配重

「嘩啦啦啦————！」

冰冷刺骨的深海水流，如同無數條狂暴的巨蟒，自被鑽裂的青銅外廊縫隙中瘋狂湧入！

短短三十秒內，海水就已經淹沒了所有人的膝蓋，水位正以每秒兩公分的恐怖速度急劇上漲。水流沖擊在燈塔那扇高達十公尺的「阿基米德浮力重壓水門」上，發出震耳欲聾的金屬呻吟。

老莫里斯抹了一把鬍子上的鹽水，指著門樑兩側三根粗大透明的承壓水銀玻璃計量柱，焦急地大喊：

「水門的開關由左、中、右三組互通的水銀浮力配重艙（$V_1, V_2, V_3$）控制！它們分別連接著三條長短不一的差動齒輪槓桿力臂（$L_1 = 1\,\text{m}, L_2 = 2\,\text{m}, L_3 = 3\,\text{m}$）！」

「黑潮的鑽機破壞了三組水箱的初始壓力平衡！如果三組浮箱產生的反向托舉力矩不能在**一百八十秒內**完全相等，門軸就會被外側 100 個大氣壓的深海水壓硬生生扭斷！整座燈塔的菲涅耳水晶透鏡將會被徹底壓碎！」

青銅門樑上的紅色倒數計時，正冰冷無情地瘋狂跳動：

> `[WARNING: 距離門軸金屬疲勞極限剩餘：89秒、88秒……]`  
> `[左力臂 L1 = 1m ｜ 中力臂 L2 = 2m ｜ 右力臂 L3 = 3m]`  
> `[總注水配重格數：11 格（必須一次性分配完畢！）]`  
> `[請立即旋動三組注水轉輪，設定排水配重比 V1 : V2 : V3！]`

「十一格總水量！力矩平衡（Torque Equilibrium）！」

葉旖緁一腳踩在凸起的青銅閥門基座上，抹開眼鏡上的水霧，手中的鋼筆在防水筆記本上劃出刺耳的摩擦聲：

「阿基米德浮力定律：浮箱產生的向上托舉力 $F$ 與排開液體體積 $V$ 成正比（$F \propto V$）！」  
「槓桿力矩平衡條件：力矩 $\tau = F \times L$！要讓三條不同長度的槓桿對水門產生的平衡力矩完全均等（$\tau_1 = \tau_2 = \tau_3$），浮箱體積 $V$ 與力臂長度 $L$ 必須成**嚴格的反比關係**！」

$$\tau_1 = \tau_2 = \tau_3 \implies V_1 \times L_1 = V_2 \times L_2 = V_3 \times L_3$$

「代入力臂長度 $L_1 = 1, L_2 = 2, L_3 = 3$！」

旖緁的眼中閃過精準的光芒：

$$\text{設公共平衡力矩為 } 6 \text{ 個單位：}$$  
$$V_1 = \frac{6}{L_1} = \frac{6}{1} = 6 \text{ 格！}$$  
$$V_2 = \frac{6}{L_2} = \frac{6}{2} = 3 \text{ 格！}$$  
$$V_3 = \frac{6}{L_3} = \frac{6}{3} = 2 \text{ 格！}$$

「驗算總水量：$6 + 3 + 2 = 11$ 格！剛好耗盡全部十一格注水配重！」

「**排水配重比：六比三比二（6 : 3 : 2）！**」

旖緁猛地抬頭大喊：「左輪轉動六圈！中輪轉動三圈！右輪轉動兩圈！快！！」

「左輪交給我！」誠浩一把撲向左側沉重的青銅轉輪。  
「中輪老子包了！」巴克擼起袖子，雙手死死扣緊中輪把手。  
「右輪看我的！」嵐嬌叱一聲，合金船槳插進右轉輪孔洞，借力猛推！

「一！二！三……轉！！」

「嘎吱吱吱——轟隆！」

在水流漫過胸膛的最後十秒鐘，三道轉輪同時發出沉重的機油咬合聲！

左側轉輪旋轉整整六圈！中間轉輪旋轉三圈！右側轉輪旋轉兩圈！

柱內的三股水銀與重力浮子在一瞬間攀升到了同一水平基準線！

「咔噠————轟隆隆隆！！」

三具重達數十噸的液壓槓桿在同一微秒內完成了力矩平衡！厚達半公尺的阿基米德青銅重壓水門，宛如一尊甦醒的遠古金屬巨神，帶著一聲撼動海溝的巨響，轟然下砸、嚴絲合縫地閉合卡死！

底部的排水格柵同時彈開，不到三十秒，內廊洶湧的海水被高壓排水泵徹底抽空。

危機解除！

## 二、垂直八十公尺的立體發條迴廊

「呼……哈……救命……我的鞋子裡全是鹹魚味！」

將江整個人癱坐在乾燥的地板上，脫下鞋子倒出一大灘海水，大口大口地喘著粗氣。

「別抱怨了小胖子，要不是剛才關門及時，你現在已經是一條深海醃魚了。」巴克抹了把臉上的水，嘴硬地嘲笑道，但眼神中卻滿是對這幫少年不可思議的敬佩。

丁丁則蹲在一旁，拿出一塊小手帕，溫柔地替渾身濕透的皮可擦拭著金屬耳朵，皮可舒服地瞇起鏡頭，尾巴搖得像個小風扇。

誠浩擦乾護目鏡，緩緩推開了通往燈塔內部的第二重閘門。

當閘門開啟的一瞬間，所有人都被眼前的壯麗景象徹底震撼得說不出話來——

燈塔內部竟然是一個直徑達三十公尺、垂直高度整整八十公尺的巨大中空立體豎井！

這裡完全隔絕了海水，乾燥而溫暖。空氣中瀰漫著古老發條油與臭氧的特殊芳香。

更不可思議的是，在整座豎井的內部空間中，根本沒有傳統的旋轉樓梯，而是懸空咬合著數百枚大小不一、直徑從兩公尺到十公尺不等的**巨型水平青銅齒輪平台**！

「咔噠……咔噠……咔噠……」

這些青銅齒輪平台在中央巨大發條軸芯的帶動下，正以不同的齒數、不同的速度，順時針與逆時針交錯旋轉著！齒輪的咬合面雕刻著防滑的花紋，齒牙之間閃爍著微弱的金黃色熒光，宛如一座垂直懸掛在深海中的立體機械迷宮！

而在豎井的最頂端、八十公尺的高空中央，正靜靜懸浮著一座足足有三層樓高的巨大水晶透鏡——**「菲涅耳永恆大透鏡」**！

只不過此刻，透鏡的內部光束微弱如風中殘燭，只剩下一道微弱的金光，在八十公尺的頂端忽明忽暗地跳動著。

「這就是你爺爺和我們三十年前建造的『齒輪旋轉大迷宮』。」老莫里斯抬頭凝望著那座巨塔，眼中泛著無盡的追憶，「要登上頂層控制台，唯一的路徑就是踩著旋轉齒輪平台的交匯點，一路跳上去！」

「但這些齒輪的轉速各不相同！」嵐仔細觀察著前方的平台，「如果跳錯了時機，就會直接從幾十公尺的高空跌落，被下層交錯咬合的金屬齒牙碾得粉碎！」

## 三、最小公倍數與相位共振跳躍

「這不是瞎跳，這是精密的數學相位跳躍！」

葉旖緁站在起跳點邊緣，推了推眼鏡，目光瞬間鎖定了前方三組關鍵的銜接齒輪平台：

```
【齒輪迷宮跳躍相位參數】：
底層 A 齒輪（齒數 48）：每 12 秒自轉一週（逆時針）
中層 B 齒輪（齒數 32）：每 8 秒自轉一週（順時針）
高層 C 齒輪（齒數 24）：每 6 秒自轉一週（逆時針）

安全跳躍窗口：
只有當三枚齒輪的「防滑安全登陸踏板」在同一垂直軸線上重疊時，
才會形成一條維持 3 秒鐘的無縫跳躍走廊！

數學運算法則：
求解三個自轉週期的「最小公倍數（Least Common Multiple, LCM）」！
LCM(12, 8, 6) = 24 秒！

相位規律：
每隔 24 秒，三枚齒輪的金色卡槽會精準重合一次！
下一次重合倒數：7秒、6秒、5秒……
```

「**最小公倍數是二十四秒！**」

旖緁的聲音清脆堅定：「每隔二十四秒，齒輪的金色防滑卡槽會精準對齊三秒鐘！大家聽我的倒數口令，整隊一起起跳！」

「倒數三秒！三……二……一……**跳！！**」

「唰！唰！唰！」

誠浩一馬當先，腳尖在 A 齒輪的邊緣狠狠一蹬，整個人在半空中劃過一道靈巧的弧線，精準落在了剛好旋轉而來的 B 齒輪邊緣！

身後，嵐的身手宛如雨燕般敏捷，折疊船槳在空中輕輕一撐，輕盈跟上；巴克單手拎著丁丁的大衣領子，像隻矯健的山羊一樣穩穩落地；將江懷裡抱著大保溫箱，在皮可超導吸盤的拉扯下，連滾帶爬地撲上了安全平台！

「咔噠！」

就在眾人腳步落定的下一秒，身後兩枚巨型齒輪的咬合處，便帶著足以碾碎鋼板的萬噸衝量狠狠咬合在了一起，激盪出一連串耀眼的金色火花！

「好險好險……我的屁股差點就少了一半！」將江拍著心口，滿臉煞白。

「跟緊節奏！還有最後三組齒輪！下一次共振相位：十八秒後！」

在旖緁精確到毫秒級的數學倒數下，冒險小隊化身為一支配合天衣無縫的特種部隊，在八十公尺高的旋轉發條立體迴廊中穿梭跳躍。

三十公尺！五十公尺！七十公尺！

每一次起跳，都伴隨著齒輪沉悶優雅的金屬交響；每一次落地，都踏在數學與物理定律最純粹的美感之上！

## 四、爺爺的全息投影與三十小時大限

「呼——哈！」

伴隨著最後一記奮力攀登，誠浩一把抓住了頂層環形控制台的黃銅欄杆，翻身躍上了八十公尺高空的主甲板！

所有人隨後陸續登頂。

展現在他們面前的，是整座迷失燈塔的終極心臟。

直徑十公尺的菲涅耳水晶大透鏡近在咫尺，數以千計由天然水晶研磨而成的環形稜鏡，在微弱的金光下散發出彩虹般的折射光暈。

而在透鏡的正下方，擺放著一張陳舊卻一塵不染的木質航海工作椅。椅背上整整齊齊地掛著一件洗得發白的深藍色羊毛水手毛衣。

工作台中央，正靜靜擺放著一具閃爍著幽藍微光的古代全息發射台。

當誠浩胸前那枚「十二面體古代星象儀」靠近控制台的瞬間，發射台上的感應光環突然劇烈旋轉了起來！

「嗡————！」

一道純淨無暇的白色全息光柱自平台中央沖天而起，在半空中交織重組——

下一秒，一個身穿深藍色毛衣、滿頭銀髮、眼神無比溫暖堅毅的老人全息投影，帶著那抹誠浩無比熟悉的微笑，憑空出現在了所有人的眼前！

「爺爺……」誠浩的眼眶瞬間紅了，忍不住伸出手去，但手指卻只是穿過了虛幻的光影。

全息投影中的誠遠山老爺子，手裡端著一杯冒著熱氣的咖啡，目光彷彿穿透了三十年的時光，直直注視著眼前的孫子：

> 『浩浩，如果你正站在這座菲涅耳透鏡前……說明你已經成功穿越了千島齒輪海，來到了爺爺一生奮鬥的終點。』  
>  
> 『不要害怕，我現在就在這座燈塔正下方三千公尺處的“古代地熱核心大廳”。』  
>  
> 『黑潮重工的沈天成，已經徹底瘋了。他駕駛著利維坦零號，在深海地殼插下了七枚“地熱地震針”，企圖強行引爆海底火山，掠奪所有的古代結晶能量……』  
>  
> 『我正在用這裡的最後發條大陣，死死頂住地殼斷裂層……但我這把老骨頭，**最多只能再撐最後三十個小時**。』  
>  
> 『一旦三十個小時耗盡，不僅深海大裂谷會徹底塌陷，引發的超級海嘯還會將整座海風島與鹿陽國小徹底吞沒！』  
>  
> 『要重啟燈塔、瓦解地震針，你們必須拿到最後的第三把鑰匙——那是當年我藏在海風島北側**“海市蜃樓全息折射海域”**中的【天琴座光學星盤】！』  
>  
> 『時間不多了，孩子們……世界的未來，就託付給你們了！』

「滋啦啦——」

話音落下，全息投影伴隨著一陣劇烈的信號干擾，化作點點金色的光斑消散在空氣中。

三十個小時！

這是一場關乎全島、全鎮、乃至爺爺生死的最後極限倒數！

「轟隆隆隆隆————！！」

突然間，整座八十公尺高的迷失燈塔，爆發出了一陣前所未有的劇烈搖晃！

透過燈塔頂端厚重的耐壓水晶觀測窗，所有人駭然看見——

在深海大裂谷底部的漆黑海溝中，七道直徑達數十公尺、燃燒著猩紅地熱岩漿的鋼鐵巨柱，正伴隨著無比恐怖的刺耳尖嘯，如同一根根淬毒的鋼針，狠狠刺進了深海地殼的裂縫深處！

海水開始瘋狂沸騰！

大地在悲鳴，深海在咆哮！
