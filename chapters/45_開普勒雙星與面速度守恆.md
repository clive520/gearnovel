# 第十三章：開普勒雙星與面速度守恆

## 一、質心星盤與近星點卡頓

上午九點十分，天極雙星天象台頂部那具直徑十二公尺的青銅穹頂緩緩向兩側滑開，露出了浩瀚碧藍的萬米晴空。

在第十二章成功以全反射石英光纖貫穿三千公尺深淵並傳輸八十太字節的光譜數據後，天象台老守護者<u>莫拉長老</u>領著三位少年來到了中央大殿的最深處。矗立在眾人眼前的，是一座歷經百年歲月洗禮、由純青銅與因瓦合金鑄造而成的宏偉天體機械——「天極雙星質心差速星盤（Binary Barycentric Differential Astrolabe）」。

星盤的底座如同一座八角形的青銅祭壇，表面雕刻著細密繁複的黃道十二宮刻度與極座標引力網格。在祭壇正上方，兩根懸挑長臂分別托舉著一枚拳頭大小的湛藍色天輝水晶球（象徵天極藍巨星 A）與一枚略小的純金星核球（象徵伴星金矮星 B）。兩顆模擬星體由中央一套龐大的差速行星齒輪箱驅動，在半空中精準還原天極雙星繞著共同質心（Barycenter）互繞運行的宏大天象。

「按照星港古訓，唯有當這具差速星盤的實體指針與天穹雙星的真實天體軌道達成完美的秒級同步時，星港主導航信標的光束才能獲取精確的空間姿態基準。」<u>莫拉長老</u>撫摸著冰涼的青銅外殼，長長嘆了一口氣，「然而，自從六十年前雙星軌道進入大偏心率橢圓週期後，這具星盤就再也沒有成功完整運轉過哪怕一圈。」

「是因為齒輪卡頓嗎？」十三歲的學徒少女<u>采婭玆</u>俯下身來，從腰間牛皮工具袋中取出一支黃銅手電筒，細緻地照亮了差速箱內部數以百計咬合的齒輪輪齒。身旁的機械小狐狸<u>露露</u>乖巧地蹲在工作台旁，耳朵上的微型聲學探針輕輕貼在青銅機殼上，敏銳地監聽著齒輪傳動時的微弱金屬摩擦聲。

「正是齒輪卡死！」<u>莫拉長老</u>沉痛地點了點頭，「六十年前，星港科學院的前任學者們為了追求傳動精度，將內部全部換成了最經典的高精度標準漸開線均速圓形齒輪。平時運轉時看似平穩，可每當雙星運行至距離質心最近的『近星點（Periastron）』時，整座差速星盤就會發出如雷鳴般的金屬慘叫，齒輪齒面劇烈撞擊，隨即猛烈停擺卡死！」

「漸開線圓形齒輪……」站在一旁的跳級天才少女<u>林漪姉</u>推了推眼鏡，烏黑深邃的眼眸中瞬間閃過一道銳利的算力光芒，「難怪會卡死！圓形齒輪的傳動比是嚴格恆定不變的，但真實的天體在橢圓軌道上運動時，角速度根本不是常數！」

「角速度不是常數？」少年引航員<u>罧貁銁</u>轉過頭來，俊朗的臉上帶著求知的專注，「天體在太空中運動，難道不是勻速平穩的嗎？」

「在完美的正圓形軌道上或許接近勻速，但在橢圓軌道上，那是對天體物理最嚴重的誤解！」<u>林漪姉</u>走到星盤旁的計算黑板前，抓起半截粉筆，眼神中躍動著探索科學真理的熾熱光彩。

## 二、開普勒第二定律與面速度微積分

「宇宙中所有在重力有心力場下運行的天體，無論是一顆行星繞恆星，還是兩顆互相吸引的雙星，都嚴格遵循著偉大的『開普勒第二定律（Kepler's Second Law）』——也就是『面速度守恆定律（Law of Areas）』！」

<u>林漪姉</u>手中的粉筆在黑板上行雲流水般勾勒出一條優雅的偏心橢圓軌道，橢圓的焦點處標記著引力質心，清脆明晰的聲音在大廳中迴響：

```
【開普勒第二定律與有心力場角動量守恆模型】：

1. 引力有心力場的力矩為零：
   天體所受萬有引力 F 始終沿著徑向連線 r 指向質心，
   因此引力對質心的外力矩嚴格為零：
   τ = r × F = 0！

2. 角動量守恆定律（Conservation of Angular Momentum）：
   由力矩微分方程 τ = dL / dt = 0 可得：
   天體的固有角動量 L 恆定不變！
   L = μ · r² · (dθ / dt) = 常數！
   （其中 μ = m₁m₂/(m₁+m₂) 為折合質量，r 為質心距離，dθ/dt = ω 為軌道角速度）

3. 面速度守恆（Areal Velocity）：
   天體與質心的矢徑在極短時間 dt 內掃過的微元扇形面積為：
   dA = (1 / 2) · r · (r · dθ) = (1 / 2) · r² · dθ
   由此推導出面速度（面積變化率）：
   dA / dt = (1 / 2) · r² · (dθ / dt) = L / (2μ) ≡ 常數！
```

「看這道公式！」<u>林漪姉</u>用力在分母與分子上劃出強調線，「因為矢徑在相等時間內必須掃過完全相等的面積，所以當天體距離質心變近時（r 減小），為了維持面積乘積恆定，它的軌道角速度 $\omega = d\theta/dt$ 就必須急劇暴增！」

少女轉身指向天象台的雙星軌道圖表，清晰推導出極端位置的速度突變：

```
【近星點與遠星點速度比】：

• 近星點距離（Periastron）：r_p = a · (1 - e)
• 遠星點距離（Apastron）：r_a = a · (1 + e)

由角動量守恆 L = μ · r_p · v_p = μ · r_a · v_a 可得：
速度極值比：
v_p / v_a = r_a / r_p = (1 + e) / (1 - e)

• 天極雙星的軌道偏心率高達 e = 0.35：
  近遠星點速度比高達：
  v_p / v_a = (1 + 0.35) / (1 - 0.35) = 1.35 / 0.65 ≈ 2.077 倍！
  角速度之比更是高達 (1 + e)² / (1 - e)² ≈ 4.31 倍！
```

「超過四點三倍的角速度跳躍……」<u>采婭玆</u>倒吸了一口涼氣，身為鐘錶匠的直覺瞬間洞悉了機械卡死的根本死穴，「百年前的先賢們給這具星盤裝上了只能提供 1:1 均速轉動的圓形齒輪。當雙星在遠星點時，齒輪轉速還能勉強匹配；但一旦衝入近星點，真實雙星在天空中以四倍的狂暴極速飛馳，而星盤上的圓形齒輪卻還在慢吞吞地均速挪動！」

「結果就是，天象傳感器與傳動機構之間產生了致命的巨大相位差，」<u>罧貁銁</u>沉聲接道，「剛性圓形齒輪無法消化這種高達兩倍以上的動態角加速度，巨大的衝擊力矩瞬間將齒面生生卡死崩裂！」

趴在底座旁的機械小狐狸<u>露露</u>發出一聲尖細的警報叫聲，兩隻金屬耳朵向後緊貼，喉嚨裡發出齒輪受阻時緊繃的嗡鳴聲。

「要打破這個百年死局，」<u>采婭玆</u>抬起明亮的深琥珀色眼眸，注視著星盤中央被撞出深痕的青銅軸心，「我們不能再用常規的圓形齒輪。我們需要一組能『隨著旋轉角度動態改變傳動比』的奇蹟齒輪！」

## 三、晨光堂非圓齒輪與共軛節線

「動態改變傳動比的齒輪？」<u>莫拉長老</u>一愣，滿臉驚訝，「世上難道真有不是圓形的齒輪？沒有固定軸半徑的齒輪，兩齒之間如何能夠穩定嚙合、不脫齒也不卡死？」

「有的，長老！那就是機械鐘錶微雕領域中最為精妙深奧的『非圓形共軛齒輪（Non-circular Conjugate Gears）』！」<u>采婭玆</u>自信地微微一笑，解開隨身圍裙，從黑金工具包最底層小心翼翼地取出了一卷泛著微黃光澤的厚羊皮紙圖譜。

圖譜攤開在工作檯上，上面用工整細膩的工匠筆觸繪製著一對形如鵝蛋般的橢圓形齒輪，齒廓邊緣密密麻麻標注著微米級的漸開線曲率坐標。

「這是我爺爺<u>采修誠</u>在三十年前親手繪製的『變速橢圓共軛節線圖譜』，」<u>采婭玆</u>溫柔地撫摸著圖紙上爺爺留下的蒼勁筆跡，「晨光堂歷代傳承的最高祕技之一，就是為天文複雜擒縱機構研磨非圓齒輪。只要兩枚旋轉齒輪的『節線曲率半徑』之和始終嚴格等於固定中心距（r₁(\theta) + r₂(\phi) = C），且滿足瞬時純滾動無滑動條件，非圓齒輪就能在高速旋轉中實現百分之百平穩順滑的連續傳動！」

「這簡直是為開普勒第二定律量身定做的機械鏡像！」<u>林漪姉</u>的雙眼在這一瞬間爆發出難以置信的興奮光芒。天才少女推了推鼻樑上的眼鏡，修長的雙手在全息計算光幕上化作殘影，開始建立非圓齒輪節曲線與面速度守恆的微積分聯立方程：

```
【開普勒面速度非圓共軛節線微積分方程】：

1. 瞬時傳動比目標函數：
   必須完全匹配雙星軌道角速度隨真近點角 θ 的動態變化：
   i(θ) = ω₂ / ω₁ = [ (1 + e · cos θ) / (1 - e²) ]²

2. 節曲線極座標解析解（中心距 C = 180.00 mm）：
   主動齒輪節徑：r₁(θ) = C / [ 1 + i(θ) ]
   從動齒輪節徑：r₂(ϕ) = C - r₁(θ)

3. 齒面漸開線曲率半徑修正：
   為了在 e = 0.35 的極端非圓曲率下避免齒廓根切（Undercutting），
   法向模數取 m_n = 1.5 mm，壓力角在節點處動態補償：
   α(θ) = arccos[ cos(20°) · (r_base / r₁(θ)) ]
```

「計算完成！」不到十分鐘，<u>林漪姉</u>便推導出了整整七十二組極微精密點陣坐標，將全息光束投射在工作台上的一塊高純度因瓦鎢鋼胚料上，「因瓦合金具備近乎為零的熱膨脹係數，硬度高達莫氏八度。只要我們能將這組雙橢圓齒輪的齒廓加工公差控制在三微米之內，星盤就能在物理層面完美重現開普勒面速度守恆！」

「三微米公差……交給晨光堂的雙手！」<u>采婭玆</u>深吸了一口氣，戴上了單眼黃銅放大鏡與鹿皮微雕手套。

少女端坐在天象台特級超精密金剛石研磨車床前，右腳輕踩變頻腳踏板，左手扶住游標測微計，右手緊握著鑲有純金剛石刀尖的雕刻銼刀。伴隨著主軸高速旋轉發出的悅耳蜂鳴，鎢鋼胚料在她的刀尖下宛如凝固的黃金般被一層層剝離出優美深邃的幾何弧線。

「第一組節徑：六十二點四五毫米；齒頂漸開線倒角：三十二微米！」身後的<u>林漪姉</u>緊盯著光幕上的微米點陣，清晰而富有節奏地報出即時坐標。

「收到！」<u>采婭玆</u>呼吸沉靜如水，全身每一處神經彷彿都與刀尖的震顫融為一體。在單眼目鏡的四十倍視野中，那一圈如天鵝羽翼般微微隆起又緩慢收斂的非圓齒廓，在她的指尖下誕生出了令人窒息的精密與優雅。

「最後一顆齒槽研磨完成！」少女輕輕吹去金屬微屑，鑷子頂端托起了一對泛著銀藍色冷光的橢圓形雙星差速共軛齒輪。

## 四、平流層迎風校準與雙星共舞

「差速齒輪箱組裝完畢！雙星偏心擺輪就位！」

<u>采婭玆</u>敏捷地將新研磨的因瓦雙橢圓齒輪裝入星盤核心。當最後一顆微型藍鋼固定螺絲以零點八牛頓·米的標準扭矩鎖緊的瞬間，整套機構嚴絲合縫地咬合在了一起，發出一聲極其悅耳清脆的金石合鳴！

然而，就在這時，通訊終端裡傳來了天樞科學院院長<u>林嚴</u>嚴格而沉著的遠程通報：「天象台注意，星港地面望遠鏡監測到，天穹大氣對流層正刮起一股強烈的南向風切變。雙星目前的真實角坐標正受到大氣折射色散的動態偏折，如果沒有高空實時大氣擾動反饋，星盤就算擁有完美齒輪，初始對準相位只要偏差超過零點五度，差速器依然會在近星點失步！」

「地面測不到的大氣擾動，那就由我們到萬米高空親手去測！」引航少年<u>罧貁銁</u>一把拉下引航防風風鏡，朝著身邊的夥伴露出無畏的笑容，「風帆艇的翼帆配重已經調整為對流層巡航模式，<u>露露</u>，我們走！」

「汪嗚——！」機械小狐狸<u>露露</u>發出一聲高亢的清鳴，銀白色的金屬長尾在空中一甩，化作一道銀色閃電躍入了帆艇的副駕駛席。

雙聯等離子噴流引擎轟然怒吼！風帆艇在萬米絕壁邊緣拔地而起，頂著平流層下方呼嘯的側風逆流而上，瞬間穿透了稀薄的卷雲層，翱翔在純淨冰藍的萬米蒼穹之上！

「對流層大氣折射率梯度矩陣已建立！」<u>罧貁銁</u>在狂暴的風切變中穩健操舵，雙眼透過機載光學星盤死死鎖定天穹雙星。小狐狸<u>露露</u>兩隻耳朵上的激光測距探針以每秒三萬次的高頻發射脈衝，將大氣折射造成的微弧度偏差透過無線電數據鏈即時回傳給天象台！

「收到來自帆艇的動態星位修正向量！」天象台內，<u>林漪姉</u>雙手在控制終端上飛速重配參數，「真近點角 $\theta_0 = 14.28^\circ$，角加速度修正值 $\alpha_{\text{corr}} = +0.024\text{ rad/s}^2$！<u>采婭玆</u>，釋放擒縱卡榫，啟動星盤！」

「明白！」

<u>采婭玆</u>屏住呼吸，右手握緊母親留下的調音黃銅扳手，指尖以教科書般優雅穩定的動作，輕巧地撥開了星盤主重鎚的釋放擒縱卡榫！

「咔——嗒————！！」

那一剎那，沉睡百年的天極雙星差速星盤，在所有人的屏息注視下轟然甦醒！

只見那對因瓦雙橢圓齒輪開始平穩而深沉地咬合運轉！當模擬雙星轉動至平緩的遠星點時，非圓齒輪的大半徑與小半徑相遇，以安靜悠揚的極低角速度緩緩推進，如同一位從容優雅的舞者在星海邊緣輕盈漫步；

而當指針劃過橢圓軌道的長軸，呼嘯著逼近引力質心的「近星點」時，奇蹟展現了！

非圓共軛齒輪的傳動比在極座標節線的導引下順滑無比地暴增了四點三倍！青銅長臂以肉眼可見的驚人爆發力加速甩過近星點弧線，其速度曲線完全擬合了開普勒第二定律的面速度微積分，沒有半分滯澀，沒有一絲撞擊，齒面間的滑動摩擦被精確的純滾動完全取代！

「面速度監測值：$dA/dt = 128.60\text{ km}^2/\text{s}$——誤差小於萬分之零點一！完全恆定！」<u>林漪姉</u>注視著光幕上平直如水平線的監測曲線，興奮得聲音發顫！

## 五、軌道鎖定，破譯 ORBIT

「嗡——————！！！！」

伴隨著雙星指針在開普勒軌道上的完美飛馳，整座十二公尺直徑的青銅星盤爆發出了一陣深沉而悠遠的宏大共振！

那聲音宛如宇宙深處古老引力波的具象交響樂，在天象台的穹頂下久久迴盪。星盤基座上的十二道黃道晶石在角動量守恆的共鳴中自內向外逐一亮起，湛藍與金黃的雙色光束交織盤旋，在天象台半空中投射出了一座清晰逼真、與頭頂蒼穹分毫不差的三維天體橢圓星軌全息圖！
