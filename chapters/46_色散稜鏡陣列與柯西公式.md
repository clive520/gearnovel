# 第十四章：色散稜鏡陣列與柯西公式

## 一、白熾混疊與光譜極限

上午十點十五分，天極雙星天象台那具直徑十二公尺的青銅穹頂之下，剛剛經歷過開普勒差速星盤動態同步的巨大歡呼聲尚未完全平息，整座大殿的光學監測屏上，卻驟然亮起了一片刺目欲盲的熾白警報！

在第十三章成功以因瓦雙橢圓共軛齒輪擬合面速度守恆、讓差速星盤與天穹天體達成精確秒級同步後，天極雙星正好迎來了五百年一遇的軌道極致幾何——兩顆恆星雙雙衝入了距離共同質心最近的「近星點（Periastron）」。

近星點的引力潮汐摩擦如同一柄無形的宇宙巨錘，狠狠擠壓著兩顆恆星的外層電離大氣。主星天極藍巨星 A（表面溫度高達兩萬八千度，富含強烈激發的氦元素）與伴星金矮星 B（表面溫度約五千二百度，富含重金屬鐵與鈉元素）在劇烈的引力共振中，爆發出一股前所未有的超高通量帶電粒子流。兩顆恆星發出的璀璨星光在穿透萬米高空稀薄大氣後，於主望遠鏡焦點處緊密重疊，匯聚成了一道直徑半公尺、亮度超越正午太陽數百倍的純白光柱！

「警告！光譜焦平面光子探測器飽和度達到百分之九十九點九！」

通訊控制台前，天象台老守護者<u>莫拉長老</u>雙手死死按在儀表盤上，原本慈祥的面容此刻寫滿了凝重與焦慮。老人指著全息屏幕上那道宛如白熾烈焰般的光斑，聲音因緊張而發顫：「孩子們，差速星盤雖然鎖定了雙星的空間幾何軌道，但要想為整座星港的三萬噸反重力晶體注入長效能量，我們必須在雙星離開近星點前的兩個小時內，精準測算出兩顆恆星各自發射光譜中的『微震精細吸收線（Fine Absorption Lines）』，並藉此提煉出天體引力場的『共振本徵頻率』！」

「但是現在……兩顆星的光完全混成了一團白光！」十三歲的學徒少女<u>采婭玆</u>快步走到光譜儀側邊，從工具袋中取出一片高透光偏振衰減鏡擋在眼前。透過衰減鏡，少女能清晰看見光譜儀內部那枚服役了半個世紀的單片等邊石英稜鏡——在強烈的白熾光柱衝擊下，石英稜鏡雖然將白光勉強散開成了一條狹窄的光帶，但在光帶中央，藍巨星的氦吸收譜線（氦一線 447.1 奈米、587.6 奈米）與伴星的重金屬吸收譜線（鐵譜線 527.0 奈米、鈉雙線 589.0 奈米）竟然死死重疊在同一個微米區域內，互相干擾、互相湮滅，化作一片模糊不清的灰色噪聲！

「這是嚴重的『光譜混疊（Spectral Overlapping）』！」站在全息光譜分析終端前的跳級天才少女<u>林漪姉</u>推了推眼鏡，烏黑深邃的雙眸中閃爍著銳利的解析寒芒。少女修長的指尖在虛擬控制台上飛速滑動，調出了單片石英稜鏡的光學傳遞函數圖表，「這枚老式稜鏡的色散能力太弱了！它的幾何頂角只有六十度，材料只是普通的天然熔融石英。對於波長相差不足零點一奈米的雙星微震精細雙線，單稜鏡展開的光斑角寬度甚至小於光學繞射極限，所有關鍵吸收線全被雜散光吞噬了！」

「滋滋……呼叫天象台！呼叫特遣隊！」就在這時，全息終端中傳來了天樞科學院院長<u>林嚴</u>嚴肅無比的緊急通報。螢幕中，科學院中央控制大廳的紅色應急燈光瘋狂閃爍，數百名學者正在奔走呼喊，「星港中央反重力晶體矩陣出現了嚴重的三階諧波失諧！磁層防護網的相位差正在以每分鐘零點三度的速度漂移！如果不能在兩小時內將天極雙星的氦-鐵精細光譜徹底分離、計算出精確的本徵共振頻率，整座星港的反重力核心將在正午日食時發生雪崩式停擺！」

「兩小時……」十四歲的首席引航少年<u>罧貁銁</u>握緊了拳頭，英挺的眉峰緊蹙，「我們必須找到一種方法，把這道刺目的混合白光像撕開布料一樣，徹底拆解成千萬條清清楚楚的獨立光譜！」

趴在工作台邊緣的機械小狐狸<u>露露</u>發出了一聲急促的啼鳴，金屬長尾尖端彈出一枚微型分光光纖探頭，在白光光柱邊緣輕輕一掃，探測儀立刻發出尖銳的高頻過載警報。

「普通的單片稜鏡做不到，」<u>采婭玆</u>抬起清澈堅毅的深琥珀色眼眸，凝視著光譜儀中央的黃銅支架，「但如果我們改變稜鏡的材料幾何，甚至將多枚稜鏡串聯成陣列呢？」

「對！這正是波動光學中最迷人的核心領域——『非線性色散稜鏡陣列』！」<u>林漪姉</u>轉身抓起一支白板筆，眼神中綻放出洞悉宇宙物理法則的自信光芒。

## 二、柯西色散公式與最小偏向角

「為什麼白光穿過透明玻璃時會變成彩虹？這是所有光學工程的起點！」

<u>林漪姉</u>手中的白板筆在天象台的光學黑板上畫出一道晶瑩剔透的等邊三角形稜鏡，一道平行的白色複合光束從左側斜斜射入稜鏡表面。少女清澈如泉水般的聲音在大殿內清晰響起：

```
【光波色散本質與柯西經驗公式（Cauchy's Dispersion Equation）】：

1. 介質折射率隨光波長的非線性色散關係：
   光在真空中的速度為常數 c，但在光學介質中，電子極化率隨入射電磁波頻率而改變。
   由此誕生了著名的柯西經驗公式：
   n(λ) = A + (B / λ²) + (C / λ⁴) + ...

   • λ 為入射光在真空中的波長；
   • A 為材料的無量綱基本折射率常數（決定光束整體偏折基準）；
   • B 為材料的柯西色散係數（單位為 μm²，決定光譜展開的強弱）；
   • C 為高階色散係數（微米四次方，在紫外與短波長區間提供微調修正）。

2. 正常色散（Normal Dispersion）物理規律：
   由於柯西公式中波長 λ 處於分母位置，對波長求導可得色散率微分：
   dn / dλ = -2B / λ³ - 4C / λ⁵ < 0！
   由此揭示出不可動搖的物理鐵律：
   • 波長越短的光（如藍紫光，λ ≈ 400 nm）：折射率 n 越大，光速越慢，偏折角越劇烈！
   • 波長越長的光（如紅光，λ ≈ 700 nm）：折射率 n 越小，光速越快，偏折角越平緩！
```

「看這道微分式！」<u>林漪姉</u>重重敲擊著黑板上的柯西色散係數 $B$，「普通天然石英玻璃的柯西係數只有 $B pprox 0.0035\,\mu	ext{m}^2$，這就是為什麼舊稜鏡根本拉不開光譜！要想讓雙星的微震吸收線分離，我們必須採用色散係數 $B$ 高達四倍以上的特種重火石光學琉璃！」

「但是光有高色散材料還不夠，」站在一旁的<u>采婭玆</u>凝視著黑板上的光路幾何圖，身為鐘錶微雕大師的幾何直覺瞬間指出了光學上的第二大死穴，「光線在進入稜鏡和射出稜鏡時，如果入射角度不對，稜鏡會產生嚴重的光學像差——尤其是『彗差（Coma）』與『像散（Astigmatism）』！這會讓原本纖細的譜線變成一團拖著尾巴的模糊彗星！」

「說得太精確了，<u>采婭玆</u>！」<u>林漪姉</u>眼眸大亮，立刻在稜鏡內部畫出了一條與底邊嚴格平行的對稱光線，「要消除所有彗差與幾何球差、獲得宇宙級銳利光譜的唯一途徑，就是讓稜鏡處於完美的『最小偏向角（Angle of Minimum Deviation, $\delta_{\min}$）』狀態！」

少女筆尖飛轉，推導出經典稜鏡光學的黃金方程：

```
【等邊稜鏡最小偏向角與對稱光路模型】：

1. 稜鏡總偏向角方程：
   δ = (i₁ - r₁) + (i₂ - r₂) = i₁ + i₂ - α
   （其中 α 為稜鏡頂角，i₁ 為第一面入射角，r₁ 為第一面折射角，
    r₂ 為第二面入射角，i₂ 為第二面出射角，且滿足 r₁ + r₂ = α！）

2. 偏向角極小值條件（對稱純對稱光路）：
   當光線在稜鏡內部嚴格平行於底邊傳播時，發生極致幾何對稱：
   i₁ = i₂ = i_sym,   r₁ = r₂ = α / 2！
   此時偏向角達到理論絕對極小值 δ = δ_min！

3. 最小偏向角與折射率精確代數解：
   sin( (α + δ_min) / 2 ) = n(λ) · sin( α / 2 )
   ⟹ δ_min(λ) = 2 · arcsin[ n(λ) · sin(α / 2) ] - α！

4. 角分辨率（Angular Dispersion）放大倍率：
   dδ / dλ = (dδ / dn) · (dn / dλ)
   dδ / dn = [ 2 · sin(α / 2) ] / cos[ (α + δ_min) / 2 ]
   結合柯西公式：dδ / dλ = - [ 4B · sin(α / 2) ] / [ λ³ · cos((α + δ_min) / 2) ]！
```

「這就是答案！」<u>林漪姉</u>轉身看向眾人，白皙的臉頰上泛著興奮的紅暈，「如果我們只用單一稜鏡，無論材料多好，光譜角展開寬度最高也只有一點五度，投影在焦平面上也只有八公分寬，依然無法達到分開 0.05 奈米吸收線的極限要求！但如果我們將三枚特殊設計的稜鏡串聯成『三級漸進色散稜鏡陣列』——第一級火石玻璃初級分光，第二級倒置冕牌玻璃補償非線性色差，第三級超密火石玻璃二級指數放大，整體的角色散率將呈現幾何級數暴增二十四倍，將光譜展開至整整十二公尺寬！」

「十二公尺寬的彩虹……」少年<u>罧貁銁</u>倒吸了一口涼氣，「在十二公尺的光譜畫布上，哪怕相差萬分之一奈米的譜線，也將被拉開超過十公分！」

「但是，三枚稜鏡串聯意味著必須同時維持三組精準的最小偏向角對稱光路，」<u>莫拉長老</u>撫鬚的手微微顫抖，眼中滿是難以置信的驚嘆，「每一枚稜鏡的旋轉角度只要偏差千分之一度，出射光斑就會徹底偏離光軸，甚至發生全反射卡死在晶體內部！星港之中，有誰能在短短四十分鐘內研磨並校準出這種神蹟般的稜鏡陣列？」

「晨光堂可以！」<u>采婭玆</u>微微昂首，深琥珀色的眼眸中燃燒著對家族工藝的絕對自豪。少女一把解開牛皮工具袋，取出了兩枚沉甸甸、散發著深邃幽光的特種光學毛坯晶體。

## 三、晨光堂火石琉璃與微分螺旋角規

「長老請看，這是我爺爺<u>采修誠</u>在三十年前從深海玄武岩火山熱液礦脈中採掘、由晨光堂祖傳退火窯歷經九九八十一天均勻退火鑄造的頂級光學重火石琉璃（Heavy Flint Glass）！」

<u>采婭玆</u>將兩枚毛坯托在手心。左側那枚晶體通體透著淡淡的琥珀金澤，密度極高，拿在手中宛如沉重的黃金；而右側那枚則澄澈通透得如同一汪冰川融水，正是傳奇的高純度鋇冕光學琉璃（Barium Crown Glass）。

「火石琉璃內部摻入了高比例的氧化鉛與氧化鑭，折射率高達 $n_d = 1.685$，柯西色散係數高達 $B = 0.0142\,\mu	ext{m}^2$，阿貝數 $V_d = 31.2$，具有當世最為霸道強勁的色散分光力；而冕牌琉璃折射率較低（$n_d = 1.528$），色散平緩（$V_d = 58.5$），最適合用來做非線性色差的幾何校正！」

少女俐落地拉下工作台旁的金剛石超精密冷加工銑磨機護罩，將長髮高高挽起，戴上單眼四十倍游絲放大鏡：「爺爺常跟我說，光學稜鏡的靈魂在於三個要素：頂角幾何精確度、端面平面度，以及無應力固定！只要稜鏡的三個平面有任何微米級的翹曲，光波前就會發生嚴重的波前畸變！」

「銑磨主軸轉速設定：每分鐘一萬八千轉！去離子冷卻水霧啟動！」

伴隨著一聲清越悠揚的馬達嗡鳴，特製的金剛石砂輪高速旋轉起來。<u>采婭玆</u>白皙穩定的雙手握住微調進給手輪，以八字形交叉軌跡將火石琉璃胚料緩緩推進刀口。

「滋————」

極其細膩平穩的金屬與琉璃研磨聲在大殿內迴盪。小狐狸<u>露露</u>化身最高效的感測助手，靈巧的金屬爪子握著一柄激光干涉測厚儀，尾尖的光纖探針實時將干涉牛頓環條紋投射在<u>采婭玆</u>的視網膜投影儀上。

「第一面粗糙度達標：二點一奈米！牛頓環曲率小於十分之一波長（$\lambda/10$）！」

「頂角切削角度：六十點零零零度！誤差小於三角秒！」

<u>采婭玆</u>的呼吸沉靜得沒有半分起伏。每一刀進給、每一次換向，都凝聚著晨光堂三代工匠沉澱的手感記憶。僅僅用了二十五分鐘，兩枚泛著淡金光澤的等邊火石稜鏡與一枚純淨透明的冕牌消色差稜鏡，便在少女的手中奇蹟般誕生！三枚稜鏡的光學透射面在光線照耀下，宛如凝固的液態水銀般平整純粹，沒有哪怕一道微觀刮痕！

「稜鏡研磨完成！現在是核心承載機構——『微分螺旋測微測角台（Differential Micrometer Goniometer）』！」

<u>采婭玆</u>沒有絲毫停歇。她從工具箱底層取出一套由零膨脹因瓦合金精雕而成的三軸旋轉托架。這套托架採用了機械鐘錶史上最巧妙的「微分螺紋」結構：外層主螺母螺距為 0.50 毫米，內層微調螺桿螺距為 0.45 毫米。當手輪旋轉一整圈時，差動進給量僅有微小的：
$$\Delta p = 0.50 - 0.45 = 0.05\,	ext{mm} = 50\,\mu	ext{m}$$
而在手輪圓周上等分雕刻著三百六十道微細刻度，這意味著每一格微細刻度對應的直線位移僅有：
$$\delta x = rac{50\,\mu	ext{m}}{360} pprox 0.138\,\mu	ext{m} = 138\,	ext{nm}！$$

「一百三十八奈米的進給精度……」站在一旁的<u>林漪姉</u>凝視著那組精緻絕倫的金屬刻度盤，由衷地發出驚嘆，「配合三十公分的轉動擺臂，這具角規能將稜鏡的旋轉角度控制在零點一角秒之內！這已經徹底超越了星港皇家科學院所有現役實驗室設備的機械極限！」

「三枚稜鏡已依序裝入微分角規托架！」<u>采婭玆</u>用精密的黃銅扭矩扳手將最後一顆藍鋼螺絲鎖緊至零點三牛頓·米，「第一級：火石正稜鏡；第二級：冕牌倒置稜鏡；第三級：火石放大稜鏡！三級稜鏡陣列機械結構鎖定！」

然而，就在少女準備將稜鏡組推入光譜儀主光路的瞬間，天象台頂部的露天大氣感應器突然爆發出尖銳的氣壓驟降鳴響！

「警報！大氣平流層激波來襲！」通訊器中傳來了科學院監控員的驚呼，「萬米高空的急流層出現了強烈的溫度逆溫帶！大氣本身的折射率梯度正在發生劇烈紊動！大氣層此時如同一枚不斷抖動的巨型空氣稜鏡，天極雙星的光束正在以每秒數十次的頻率發生幾何偏折色散！」

## 四、平流層大氣色散補償與三稜鏡陣列

「大氣色散效應（Atmospheric Dispersion）！」

<u>林漪姉</u>猛地調出大氣光學模型，神色無比嚴峻：「當星光穿過不同高度的大氣層時，天頂角越大的星體，受到的地球大氣折射率色散就越劇烈！此時大氣層就像一枚厚度不均勻的空氣稜鏡，藍光被抬高、紅光被壓低，使得抵達望遠鏡的入射光束自身就帶有高達十二角秒的隨機動態色散色差！如果不即時進行逆向補償，我們的三稜鏡陣列會將這種大氣色差成倍放大，光譜吸收線依然會被撕裂模糊！」

「大氣的動態色散向量是多少？地面望遠鏡無法穿透高空逆溫層測量！」<u>莫拉長老</u>急聲問道。

「地面測不到，那就由我和<u>露露</u>到萬米平流層的風眼中心親自測給你們！」

一聲豪邁清越的少年長嘯在起降坪上響起！只見引航少年<u>罧貁銁</u>早已全副武裝，一身防風深藍飛行服在烈風中獵獵作響。少年的雙人引航風帆艇兩側已經加掛了兩枚超輕質氦氣平衡浮筒與高頻光學偏振探測浮標。

「<u>露露</u>，啟動雙星光學大氣感測陣列！我們出發！」

「汪嗚——！」機械小狐狸<u>露露</u>如同一道銀白色的箭矢竄入副駕駛席，鈦金屬長尾猛然化作一柄傘狀的微型天線，耳朵上的高速激光測距頭開始向著萬米天頂高速發射測量光束。

「轟隆隆隆————！！」

雙聯等離子引擎在萬仞絕壁邊緣咆哮而起！風帆艇如同搏擊長空的蒼鷹，毫不猶豫地逆著呼嘯的逆溫急流，以七十度的仰角直插平流層萬米蒼穹！

舷窗外的空氣溫度驟降至零下四十五度，狂暴的側向風切變如同無數柄利刃撕扯著機翼。但<u>罧貁銁</u>的手掌沉穩得沒有半點抖動，少年的皮膚神經感測貼片將翼面氣壓差毫秒不差地轉化為操舵修正，帆艇如同一位技藝絕頂的冰上舞者，在翻騰咆哮的氣流渦旋中靈巧穿梭，精準懸停在距離天象台頂峰兩千公尺的正上方！

「大氣色散層核心參數捕獲！」<u>罧貁銁</u>洪亮清晰的聲音穿透無線電靜電，在天象台內炸響，「當前天頂角六十二度四分！平流層氣壓四百五十百帕，大氣色散柯西動態補償量：$\Delta n_{\text{atm}}(\lambda) = +0.000185 \cdot (1 + 0.0056/\lambda^2)$！光軸偏折角：負八點四二角秒，偏振方位角：二百一十四度！」

「收到大氣色散逆向矩陣！」天象台內，<u>林漪姉</u>的手指在全息終端上化作了一片模糊的殘影，「微分角規補償角度計算完畢！第一稜鏡偏轉補償角：正兩分三十六秒；第二稜鏡反向抵消：負四分一十二秒；第三稜鏡鎖定最小偏向角：五十一度四十八分二十二秒！」

「<u>采婭玆</u>，動用微分角規，旋轉刻度盤！」

「交給我！」

<u>采婭玆</u>深吸一口氣，纖細而堅定的指尖輕輕搭在微分測微手輪的黃銅滾花邊緣。少女合上雙眼，不再依賴肉眼的觀察，而是完全釋放出晨光堂工匠融入血脈的指尖觸覺記憶。

「噠、噠、噠……」

因瓦合金微分螺桿在微米級潤滑油的滋潤下順滑無聲地旋轉。第一組手輪轉過整整兩圈又一百八十四格；第二組手輪反轉一圈又九十二格；第三組手輪精準推至第五百一十六格刻度線！

「咔嗒！」

三枚晶瑩剔透的稜鏡在半空中呈現出一種精巧至極的幾何夾角，形成了一條完美無瑕的階梯式對稱折射光路！

「大氣色散動態抵消！三級稜鏡最小偏向角完全對準！」<u>林漪姉</u>猛地拉下主光閥，「釋放雙星白熾光束，導入色散陣列！」

## 五、十米彩虹光譜，破譯 PRISM

「轟——————！！！」

那一瞬間，整座沉寂百年的天極雙星天象台大殿，被一道無法用言語形容的宏偉光學奇蹟徹底照亮！

只見那道匯聚了雙星極致能量的刺目純白光柱，自聚光鏡焦點呼嘯而入，直直貫穿了第一枚重火石等邊稜鏡！

在柯西公式的物理法則支配下，白光內部的各色光子依照波長長短，在火石琉璃內部被精準剝離！藍紫光以大角度向下偏折，紅光以小角度向上飛掠；緊接著，初級展開的光帶穿入第二枚倒置的冕牌琉璃稜鏡，非線性色散幾何像差在瞬間被撫平抵消；最終，純淨的光波衝入第三枚高密度火石稜鏡——

「嗡——————！」

幾何級數暴增二十四倍的強烈角色散，在第三稜鏡的後方化作了一場震撼靈魂的星光爆發！

原本只有半公尺粗細的混濁白光，在脫離稜鏡陣列的剎那，如同孔雀開屏般在半空中轟然展開，化作了一道橫跨天象台整面弧形大理石牆壁、長達整整十二公尺的壯麗彩虹光譜巨幕！

從最左側幽深縹緲的近紫外深紫（380 奈米），到湛藍、天青、翡翠綠、明黃、暖橙，再到最右側如熔岩般深邃熾烈的深紅（760 奈米）——整座大殿完全沐浴在浩瀚絢爛的純淨七色光海之中！

更令全場所有人熱血沸騰、屏住呼吸的是光譜巨幕上的微觀奇蹟——

在長達十二公尺的光譜畫布上，原本死死混疊在一起的雙星光譜，被分離得涇渭分明！

只見屬於天極藍巨星 A 的氦一特徵吸收譜線（447.1 奈米處），如同一道被極細鋼刀裁出的墨黑細線，銳利、冷冽、高傲地矗立在藍光波段中央；而屬於伴星金矮星 B 的鈉雙重吸收線（589.0 奈米與 589.6 奈米），則在明黃色的光帶中被整整拉開了八公分的距離，兩根細如髮絲的暗線並肩而立，清晰得連最微小的吸收輪廓震顫都纖毫畢現！

「分開了……徹底分開了！！」<u>林漪姉</u>激動得眼淚奪眶而出，手中的光度感測筆在兩道譜線之間飛速劃過，「雙星精細光譜分辨率達到萬分之零點零二奈米！光學色散極限被打破了！」

「立即提取共振特徵頻率！」天象台光譜電腦開始瘋狂解碼兩顆恆星的微震數據：
$$f_1(	ext{藍巨星 He}) = 6.708 	imes 10^{14}\,	ext{Hz}, \quad f_2(	ext{金矮星 Na}) = 5.089 	imes 10^{14}\,	ext{Hz}$$
「雙星共振特徵向量生成！上傳星港天樞科學院！」<u>林漪姉</u>用力敲下回車鍵！

三秒鐘後，通訊終端中傳來了整座星港數萬名學者近乎瘋狂的歡呼與掌聲！

天樞科學院院長<u>林嚴</u>那向來沉穩嚴厲的聲音，此刻激動得幾近哽咽：「收到完美雙星微震頻率！全城三萬噸反重力晶體矩陣三階諧波共振已完全消除！磁層防護網相位誤差清零！整座奇蹟之城……徹底穩固了！！孩子們，你們用稜鏡為星港挽救了一場滅頂之災！」

就在這時，十二公尺長的彩虹光譜正中央，在那組被完美分離的黃金光譜帶核心，由三級稜鏡陣列的最小偏向角對稱光斑精準折射出了一道懸浮在半空中的璀璨金色文字序列：

```
【色散稜鏡陣列 · 第 14 章啟航密碼解密】：

密文數列：[ 16 - 18 - 09 - 19 - 13 ]

• 16 ➜ 第 16 個英文字母：P
• 18 ➜ 第 18 個英文字母：R
• 09 ➜ 第 9 個英文字母：I
• 19 ➜ 第 19 個英文字母：S
• 13 ➜ 第 13 個英文字母：M

【解密結果】：P - R - I - S - M ⟹ PRISM（色散稜鏡／光譜之門）！
「當白熾的光束被誠實地分開，每顆星辰便擁有了屬於自己的顏色；
  科學是拆解光芒的稜鏡，而愛是讓所有色彩重歸純粹的奇蹟。」
```

「PRISM……稜鏡！是色散稜鏡！」<u>采婭玆</u>仰望著半空中那行在彩虹光芒中熠熠生輝的字母，臉上露出了無比燦爛的笑容。

風帆艇破空而歸，穩穩降落在天象台的陽光起降坪上。少年<u>罧貁銁</u>跳出座艙，帶著高空的微寒與陽光的溫暖快步走進大殿；小狐狸<u>露露</u>發出歡快的鳴叫聲，在十二公尺長的光譜彩虹中靈巧地躍動追逐著光斑，金屬尾巴被七彩的光芒染得如同夢幻般絢麗。

老守護者<u>莫拉長老</u>撫摸著溫熱的因瓦測角台，眼含熱淚地向著三位少年深深一躬：「百年來，世人皆道稜鏡只能分光，卻不知唯有心靈如晶體般純澈之人，方能看懂每一道光譜背後沉澱的宇宙真理。你們今天所做的一切，足以讓百年前建造這座天象台的先賢們含笑於九天之上。」

遠處的晨光堂工坊裡，老掌門<u>采修誠</u>站在敞開的雕花窗前，望著天象台方向升起的七彩祥光，欣慰地撫鬚大笑，眼角閃爍著驕傲的淚花。

正午的陽光普照整座琉光星港。懸浮之城的反重力光環在天頂雙星的共振頻率中綻放出純淨澄澈的碧藍神芒，三千艘風帆艇與飛艇在彩虹般的星光中穿梭巡航。手握齒輪、微積分與色散稜鏡的少年們並肩站在萬米絕壁之巔，他們的目光穿透了七彩的光譜，正向著更加遼闊、更加神祕的宇宙深空，勇敢無畏地邁出堅實的下一步！
