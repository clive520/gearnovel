# 第二十章：老守燈人的三十年約定

## 一、三千米地心的熔岩聖殿

「呼嘯————！」

高壓鈦合金升降機在垂直的玄武岩豎井中以近乎自由落體的極限速度瘋狂下墜。

艙壁外側原本冰冷徹骨的岩層，隨著深度的急劇增加，溫度開始瘋狂飆升。從攝氏二十度、五十度、一直攀升到令人窒息的八十度！特種防熱裝甲外層的水珠瞬間蒸發成一片片白色的灼熱蒸汽。

「嗡——喀啦啦！」

在下墜整整三千公尺、儀表盤指針精準撞上底線的一剎那，底部的超導反向磁煞系統猛然啟動！

強大的過載推背感將所有人緊緊壓在減震座椅上，升降機的十二組液壓緩衝支柱「轟」的一聲重重砸落在厚重平整的花崗岩基座上！

厚達三十公分的雙層防爆氣密門，伴隨著一聲悠長的洩壓氣浪，朝兩側緩緩滑開。

當所有人走出升降機的瞬間，眼前的景象，讓四個孩子與皮可的呼吸在同一微秒內徹底停滯——

這是一座深藏在地殼深處、方圓超過一公里的古代地下熔岩聖殿！

頭頂是宛如繁星般密密麻麻咬合的巨型青銅發條齒輪穹頂；腳下，數條奔騰咆哮的暗紅色地熱岩漿河，在厚達半公尺的透明天然金剛石防熱地磚下靜靜流淌，將整個宏偉的地下世界照耀得如同燃燒的赤紅神殿。

而在聖殿正中央那座高達三十公尺的中央懸空控制橋上，一座由七根數十公尺粗的烏鋼發條巨柱構成的**「地殼發條錨定陣列」**，正伴隨著地脈的顫抖發出令人心驚膽戰的金屬哀鳴。

此時此刻，在那座巨大陣列的主操縱桿前，正孤零零地站著一個蒼老卻如松柏般挺拔的身影。

他穿著一件被高溫機油浸透的深藍色粗線水手毛衣，雙手死死握著一根碗口粗細的重型手動張力絞盤，渾身的肌肉因承受數千噸的發條拉力而劇烈顫抖，汗水順著他那布滿溝壑的蒼老臉龐滾滾滑落，滴在滾燙的地磚上瞬間化作青煙。

在他的胸前，掛著一隻擦得鋥亮的黃銅雙齒輪懷錶。

額頭上，推戴著一副鏡架磨損嚴重、鏡片上滿是微雕代碼的初代光學護目鏡。

「爺……爺爺？！」

誠浩的大腦在這一瞬間一片空白，兩行滾燙的熱淚毫无徵兆地決堤而出！

## 二、三十年的重逢與守燈人誓約

站在絞盤前的老人渾身猛然一震。

他吃力地轉過頭，布滿血絲的雙眼穿過蒸騰的熱浪，落在了那個穿著橙色救生背心、戴著黃銅護目鏡的少年身上。

老人那雙歷經無數風暴與孤獨歲月的眼睛裡，先是閃過一抹難以置信的恍惚，緊接著，化作了無盡的溫柔與驕傲。

「浩浩……」

誠遠山老爺子的聲音沙啞得如同砂紙摩擦，但中氣依然無比充沛：「你這臭小子……真把爺爺的護目鏡……戴著找來了啊！」

「爺爺！！」

誠浩再也忍不住，發瘋似地衝過長長的花崗岩廊橋，一把死死撲進了老人的懷抱裡！

老人用滿是老繭和燙傷痕跡的溫暖大手，緊緊抱住了孫子的肩膀，笑著拍了拍誠浩的後背，眼角泛起了淚光：

「長高了……長結實了！像個頂天立地的真正男子漢了！」

趴在誠浩腳邊的皮可，兩隻幽藍色的鏡頭歡快地閃爍成兩道月牙，小腦袋親暱地使勁蹭著老人的褲腿，發出一陣陣撒嬌般的「嚶嚶」電子歡叫。

「好皮可……」老爺子蹲下身，慈祥地撫摸著銀色機械犬的小腦袋，「你的記憶合金外骨骼保養得很好，誠浩這孩子沒虧待你吧？」

「汪！汪！」皮可興奮地立正敬了個禮。

此時，葉旖緁、嵐與將江也快步走上了控制台。

誠遠山抬起頭，目光掃過三個年輕的孩子，眼中滿是讚許的光芒：

「這位是葉家的小姑娘吧？你眉宇間的這股靈氣與專注，簡直跟你父親當年一模一樣；」  
「還有嵐……海風島暴風領航員的血脈，在你的眼神裡燃燒著，你爺爺當年的水手刀，想必傳給你了吧？」  
最後，老爺子的目光落在了將江手裡那口黑漆漆的老鐵鍋上，忍不住爽朗地大笑出聲：  
「哈哈！還有這個背平底鍋的小胖墩！三十年前我們船上的廚子也是這副行頭，走哪都不忘帶著油鹽醬醋！」

將江不好意思地撓了撓圓圓的平頭，連忙從懷裡掏出一塊用錫箔紙包好的菠蘿麵包，雙手遞了上去：

「誠爺爺！您辛苦了！這是我親手烤的特級菠蘿麵包，還熱乎著呢，您快補充點熱量！」

老爺子接過麵包，咬了一大口，眼眶微濕地咀嚼著，連連點頭：「香！真香啊！這是我這三十年來，吃過最溫暖的一頓飯！」

擦了擦嘴，老爺子神情鄭重地望向身後震顫不休的地熱陣列，長嘆了一口氣：

「孩子們，你們一定很想知道，三十年前到底發生了什麼。」

「三十年前，我和邱校長、老莫里斯駕駛著青木齒輪號，在千島海域勘測時意外發現了這座沉睡在地底的古代文明核心。這座地熱陣列，實際上是整個西太平洋構造板塊的『地殼減震發條』。」

「當時，黑潮重工的前任董事長就企圖炸開地熱核心掠奪結晶。為了保護這片海域不被撕裂，我們三個人立下了**『三十年守燈人誓約』**——」

「邱校長回到陸地，守護齒輪鎮與鹿陽國小的孩子們，建立地面的情報防線；莫里斯留守海面，用迷失燈塔的燈光警戒群島的異動；而我……則深入三千公尺地心，與這座古老的發條大陣融為一體，守護地脈的安寧。」

老爺子的目光轉向誠浩，神色無比凝重：

「但是現在，沈天成那畜生在周圍的地殼裂縫中刺入了**『七根地熱地震針』**！高壓蒸汽正以每秒數千噸的速度注入斷層，整座發條大陣……最多只能再撐最後**二十分鐘**！」

## 三、七星正多邊形與質數步長阻尼矩陣

「二十分鐘？！」將江手裡的平底鍋差點嚇掉在地上。

「不能直接把那些地震針拔出來嗎？」嵐急切地問道。

「絕對不行！」誠遠山老爺子嚴厲地搖頭，「地震針深插地殼核心，內部充滿了超臨界態的高壓地熱流體。如果暴力強拆，會引發瞬間的『減壓沸騰（Cavitation Blowout）』，數萬噸的熾熱岩漿會像高壓水槍一樣噴穿地表，直接掀起百米超級海嘯！」

「唯一的解法，是用天琴座光學星盤的共振頻率，依序向七根地震針注入**『反相抗震阻尼矩陣』**，讓它們內部的高壓共振逐步歸零！」

葉旖緁快步走到主控光幕前，手指在全息投影的七根地震針坐標圖上飛速比對：

```
【地殼地震針阻尼消減矩陣】：
陣列幾何構型：正七邊形（Heptagonal Array）
編號標註：環形順時針標註為 1, 2, 3, 4, 5, 6, 7

地熱脈動基頻：f₀ = 7.5 Hz
每根地震針諧波頻率：f_k = k × f₀（1至7階諧波疊加）

消減禁忌：
若按相鄰順序（1➡️2➡️3...）消減，相鄰兩針的頻率差（Δf = 7.5 Hz）
將引發局部劇烈的「低頻拍頻共振（Beating Phenomenon）」，直接震裂地殼！

數學拓撲消減法則（尤拉質數步長循環 / Hamiltonian Step）：
利用正七邊形的對角星形折線，選取與 7 互質的跳步步長 s = 2！
模運算狀態轉移方程：
k_next = (k_curr + 2) mod 7
（計算結果若為 0，則映射為第 7 號針！）

起始基點：以能量最低的 1 號針為起點！
```

「**質數步長模運算（Modular Arithmetic）！星形拓撲消振法！**」

葉旖緁的雙眼閃爍著數學之美：「大家看！這七根針構成了一個正七邊形！如果相鄰拔除，會產生致命的低頻拍頻！必須採用**步長為二**的跳步模運算！」

旖緁迅速在地上寫出算式：

$$\text{第 1 步：} k_1 = 1$$  
$$\text{第 2 步：} k_2 = (1 + 2) \bmod 7 = 3$$  
$$\text{第 3 步：} k_3 = (3 + 2) \bmod 7 = 5$$  
$$\text{第 4 步：} k_4 = (5 + 2) \bmod 7 = 7 \quad (\text{因為 } 7 \bmod 7 = 0)$$  
$$\text{第 5 步：} k_5 = (7 + 2) \bmod 7 = 9 \bmod 7 = 2$$  
$$\text{第 6 步：} k_6 = (2 + 2) \bmod 7 = 4$$  
$$\text{第 7 步：} k_7 = (4 + 2) \bmod 7 = 6$$

「消減序列出爐！」旖緁猛然抬頭，聲音清脆果斷：

「**一號 ➡️ 三號 ➡️ 五號 ➡️ 七號 ➡️ 二號 ➡️ 四號 ➡️ 六號！**」

「誠浩！轉動天琴星盤的七芒星撥輪，按照這個序列依序發射反相激光阻尼脈衝！！」

「明白！」

誠浩深吸一口氣，雙手穩穩托起合體的神器。天琴座光學星盤中央的七芒星校準指針，在誠浩穩定的指尖下發出清脆的「咔噠」咬合聲！

「一號針——脈衝注入！！」

「嗡！」一道金藍色的激光自星盤射出，遠方一號地熱巨柱的猩紅光芒瞬間熄滅！

「三號針——注入！！」

「五號針——熄滅！！」

「七號針——熄滅！！」

伴隨著一根根地震針的過載被平穩化解，地熱大廳劇烈的震顫開始奇蹟般地平息，金剛石地磚下的岩漿流速肉眼可見地減緩了下來！

## 四、浴血的莫里斯與電鋸惡魔

「成功了！只剩最後兩根了！」嵐興奮地揮舞起合金船槳。

然而，就在誠浩將星盤對準「四號針」的最後一瞬間——

「轟隆隆隆————！！」

身後的垂直升降機豎井頂部，突然傳來了一陣令人膽寒的恐怖爆炸巨響！

緊接著，整部重達十噸的鈦合金升降機，在無數斷裂的鋼纜與刺目的火星中，如同一顆燃燒的隕石，自三千米高空狠狠砸落在聖殿邊緣的空地上，摔得四分五裂！

而在廢墟的烈火與濃煙之中，一尊高達三公尺、通體塗裝著血紅色反光漆的**「重型外骨骼動力裝甲」**，踏著沉重得令地磚龜裂的鋼鐵步伐，緩緩走了出來！

裝甲的手臂上，兩柄高速旋轉、燃燒著兩千度等離子電漿的**「高頻熱熔鏈鋸」**，正發出令人毛骨悚然的刺耳蜂鳴！

駕駛艙的面罩緩緩掀開，露出了沈天成那張滿是鮮血、徹底癲狂的扭曲面孔：

「哈哈哈哈……誠遠山！你以為藏在地心，我就找不到你了嗎？！」

而在沈天成裝甲巨爪的後方，拖拽著一具已經嚴重變形的深海緊急逃生救生球。

救生球的透明觀察窗上布滿了蛛網般的裂紋，老莫里斯滿頭是血地倒在裡面，身上的水手雨衣被撕裂成了布條，胸口微弱地起伏著，顯然在剛才的燈塔頂層死鬥中遭受了致命重創！

「莫里斯爺爺！！」嵐看見老人的慘狀，眼淚瞬間奪眶而出，雙手握緊船槳就要不顧一切地衝上去！

「嵐！別過去！那是黑潮最殘暴的『單兵決戰型等離子泰坦』！」誠遠山老爺子一把將嵐死死護在身後，眼神冷得如極地玄冰。

沈天成揮動著滋滋作響的熱熔鏈鋸，居高臨下地指著控制台上的老爺子與誠浩，嘴角咧開一個令人作嘔的殘忍弧度：

「老東西，還有你們這群自作聰明的小雜種。」

「七根地震針，你們拔了五根對吧？很了不起啊！」

沈天成猛地按下了裝甲胸口的一顆紅色自毀開關，獰笑道：

「但是只要剩下最後一根，我體內的微型冷核動力爐就能引爆它！今天，要麼把星穹密鑰給我交出來……**要麼，你們所有人和這座深海聖殿，一起在地心熔岩裡化為灰燼吧！！**」

「嗡————！」

兩柄等離子熱熔鏈鋸同時拉滿最大轉速，如同一陣毀滅一切的烈焰風暴，帶著撕裂地面的火花，朝著誠浩與誠遠山當頭狠狠劈落！

距離最後的自毀引爆，只剩下最後——**十五分鐘**！
