# 療癒短篇小說集《手作少女的奇幻旅程》
## 專案企劃、世界觀設定與人物大綱

---

## 🎯 一、作品基本資訊與定位

- **書名**：《手作少女的奇幻旅程》（英文：*The Handmade Girl's Fantastic Journey*）
- **類型**：療癒溫馨 / 輕奇幻 / 校園成長短篇小說集
- **目標讀者**：國小中高年級～國中生（9–15 歲），兼顧全年齡層讀者
- **風格特色**：
  - **脫離現實 × 結合現實**：素描本與手作成品能通往另一個世界的輕奇幻，撞上寫實的校園、家庭與人際日常
  - **溫暖、細膩、有後勁**：以「手作修補破碎的心」為核心，用四篇獨立故事，帶出親情、友情、跨代與自我療癒
- **結構**：同一主角的四篇獨立短篇小說，可單獨閱讀；四篇情感深度漸進（親情→友情→跨代→自癒）

---

## 🌍 二、世界觀設定（統一規則表）

### 核心設定：作品通往另一個世界
主角柳奷纭有一個祕密能力——當她**完成一件注入真摯情感的作品**（一幅畫或一件手作），她就能通往「那件作品構成的世界」。

### 世界觀規則（四篇前後一致）
| 規則 | 內容 |
| :--- | :--- |
| **進入條件** | 完成一件「注入真摯情感」的作品（畫／手作皆可） |
| **進入方式** | 依各篇情節彈性：從素描本進入、或從完成的手作成品進入（碰觸、專注、強烈情緒時） |
| **世界特徵** | 作品世界是「心的投影」——反映創作當下的心境與想傳達的情感；世界裡的「人」，是作品中描繪的形象 |
| **規則一** | 不能改變作品世界裡的人（不能操控或改造，只能理解與感受） |
| **規則二** | 不能從作品世界帶回實體物 |
| **規則三** | 進入期間，現實世界的時間幾乎靜止（或極短暫） |
| **規則四** | 離開時會帶回「領悟」——那才是真正的禮物 |
| **規則五（重要）** | 過度逃避現實、只想留在作品世界是危險的（可能不想回來）——這是第四篇的深度所在 |
| **象徵** | 她修補的每一顆破碎的心，其實也是她自己的一部分 |

### 主題核心
「手作修補破碎的心」——奷纭透過一次次穿越，幫助身邊的人找回情感；而在這個過程中，她也一點一點，療癒著自己。

## 📖 四、四篇故事大綱（情感深度漸進）

### 第一篇【親情】《把全家畫回來》
> 修補的第一顆心：家人之間的裂痕。

奷纭的父母最近常常吵架、工作忙碌，全家已經很久沒有好好坐在一起吃一頓飯。她畫了一幅「理想中的全家福」——一家三口在鳳凰樹下笑。當她完成這幅畫，她走進了畫裡那個「理想的家」，遇見了畫中「理想的爸媽」，理解了現實中父母爭吵與忙碌背後，其實藏著對這個家的愛與壓力。回到現實後，她用這幅畫和一張手作的「家庭卡」，讓家人重新坐在一起，找回家的溫度。

> **手作小點子**：畫一張「全家福」，或做一張送給家人的感謝卡。

### 第二篇【友情】《給誤會的那顆星》
> 修補的第二顆心：同儕之間的誤會與隔閡。

奷纭因為沉浸美術，被同學誤解為「孤僻、不屑跟大家一起玩」，與一位其實想接近她的同學產生了誤會，雙方都受了傷。她做了一顆黏土小星星，卻遲遲送不出去。當她完成星星，她進入了那片夜空世界，遇見了「那顆代表同學的心」，理解了對方藏著的孤單與善意。回到現實後，她鼓起勇氣把星星送出去，坦承誤會，修補了友情。

> **手作小點子**：做一顆黏土小星星，送給想和好的人。

### 第三篇【跨代】《陪阿嬤走進她的畫》
> 修補的第三顆心：長輩心中逐漸流失的記憶與情感。

奷纭的阿嬤失去老伴後，記憶越來越模糊，常常對著舊照片發呆，偶爾會忘了回家的路。奷纭在整理阿嬤的舊畫冊時，發現了一幅未完成的畫。她完成了那幅畫，走進了阿嬤年輕時的世界，見到阿嬤與阿公最美好的回憶，也幫阿嬤「找回了」那些記憶。回到現實後，她把完成的畫送給阿嬤，用陪伴與創作，讓阿嬤再次想起生命裡最溫暖的時光。

> **手作小點子**：整理家人的舊照片，或幫長輩完成一件未完成的創作。

### 第四篇【自癒】《畫給自己的天空》
> 修補的第四顆心：一直以來，奷纭自己那顆被忽略的心。

前三篇裡，奷纭一直在幫助別人。可是其實，她自己也很破碎——被誤解的委屈、總是一個人的孤單、渴望被理解卻說不出口。她畫了一幅「只有一個人的天空」，那是她最真實的心情。當她進入自己的天空世界，她遇見了「畫中的自己」，終於面對了自己一直逃避的孤獨，學會自我接納。她終於明白：修補別人的心，其實也在修補自己。結局，她打開了心門，讓同學們走進她的世界——她不再孤單。

> **手作小點子**：畫一幅「給自己的天空」，寫下想對自己說的話。

## 📚 五、寫作格式規範（對照前作）

- 每篇為獨立短篇小說，約 **8000–10000 字**（純中文字元）
- **中英對照**：每篇配 `_EN` 英文版，段落 1:1 對齊
- 每篇開頭以 **2–3 句輕描主角與穿越設定**，讓單篇讀者也能進入故事
- 每篇結尾附「**手作小點子**」
- 章節檔名：`第01篇_把全家畫回來.md`／`第01篇_把全家畫回來_EN.md`（類推）
