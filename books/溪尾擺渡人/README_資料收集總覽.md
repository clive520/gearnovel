## 💡 關鍵田野亮點提煉

1. **地理定位**：臺中烏日最南端、隔烏溪與喀哩對望，南臨彰化芬園，昔稱「臺中的澎湖」。
2. **大河水性**：烏溪為荒溪型河川，暴雨時如猛獸，枯水時露出大片沙洲，築堤後將溪尾寮擋在堤外。
3. **名詞解謎**：語音輸入之「烏溪主題房」實為百年防洪治水的「**烏溪堤防**」，現代已延伸出「水岸生態主題廊道」。
4. **擺渡情懷**：林權榮、林權吉兄弟長年守護，豐水期划大竹筏、枯水期架竹便橋，風雨無阻接送學生與急難病患。
5. **土地豐饒**：全里三分之二為農田，「烏溪糧倉」冠軍米揚名國際，結合擺渡記憶推動食農傳承。
