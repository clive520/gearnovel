# 《全班作弊中》

## 第四章：咳嗽密碼與摩斯手勢

「各位！紙飛機陣亡、橡皮筋陣亡、溜溜航空也陣亡了！」

放學後的教室裡，阿釁站在課桌上，兩手叉腰，氣勢磅礡：

「但是！我剛剛發現一個最重要的關鍵——前三場戰鬥，我們都輸在『身上帶著東西』！只要帶著東西，就會被掃描！」

「所以咧？」老巫啃著肉包，含糊地問。

「所以這次！」阿釁「啪」地一拍手，「我們什麼都不帶！用『信號』！」

他轉身，在黑板上畫出密密麻麻的符號：

「第三號計畫：暗號大作戰！規則如下——」

「摸左耳，答案A！」
「摸右耳，答案B！」
「摸鼻子，答案C！」
「摸下巴，答案D！」
「咳嗽幾聲，就是第幾題！」

「也就是說——」阿釁興奮地比劃，「你咳嗽兩聲，就是告訴大家：第二題要出動了！然後你再摸一下左耳，大家就知道：第二題答案是A！」

「哇——！」老巫眼睛瞪得溜圓，「這、這不是武俠片的暗號嗎！」

「那是當然！」阿釁得意洋洋，「這次沒帶任何紙條，高老師就算掃描一千遍，也掃不到東西！因為答案，就藏在你我之間！」

「從資訊理論的角度來說……」晴晴推了推眼鏡，「這個系統有一個致命缺陷。」

「什麼缺陷？」阿釁問。

「咳嗽是聽覺信號，摸耳是視覺信號。」晴晴平靜地分析，「兩種信號，都需要『傳遞者』和『接收者』同時注意。只要有一個人漏看、漏聽，整串信息就會斷掉。」

「所以我們要訓練！」阿釁大手一揮，「全員！開始排練！」

於是，一場荒謬絕倫的「暗號特訓」，在六年一班的地下教室如火如荼地展開了。

「咳！」

阿釁清了一下喉嚨，然後摸了一下左耳。

「第二題……不，等一下！」老巫慌慌張張地站起來，「阿釁，你咳嗽一聲，到底是第一題，還是第二題？」

「咳嗽一聲，就是第一題啊！」阿釁無奈地嘆氣，「老巫，你的記性被肉包塞住了嗎？」

「可是我剛剛明明聽到你咳了兩聲啊！」老巫委屈。

「那一聲是我真的在清喉嚨！不是暗號！」阿釁暴跳如雷。

「那、那怎麼分得出來嘛！」老巫哀嚎。

「咳跟『咳』，節奏不一樣！」阿釁示範，「暗號咳嗽要短促有力——『咳』！一般咳嗽是拖長音的——『咳咳咳』……」

他話還沒說完，尪伝恺就真的打了一個超大的噴嚏：

「哈——啾！」

全班「唰」地一聲，同時摸向自己的左耳、右耳、鼻子、下巴，亂成一團。

「誰打噴嚏！誰！重傷！」阿釁氣得跳腳，「打噴嚏不算暗號！不準在考場打噴嚏！」

「我、我忍不住啊！」尪伝恺揉著鼻子，委屈地辯解。

晴晴默默地在角落寫了一張紙，遞給阿釁：

「建議：建立『訊號過濾系統』。所有動作，必須重複兩次才算數。例如摸耳朵兩次，才代表答案B。」

「重複兩次？」阿釁沉吟，「這樣不是更慢嗎？」

「但至少不會被噴嚏、咳嗽、眨眼干擾。」晴晴說，「情報的正確性，比速度重要。」

「好！就依妳的！」阿釁拍板，「全員記住！以後所有暗號，一律重複兩次！」

月考前一週，第三次模擬考，準時登場。

阿釁坐在最後一排，負責當「總機」；老巫坐在第一排，負責接收。為了避免露餡，全班二十五人（未晞不參加），全部戴上了口罩。

考卷發下來。

第一題。阿釁在心裡默數：「一！」他清了一下喉嚨：「咳——咳——」

然後，他迅速地摸了兩下左耳。

老巫屏住呼吸，在心裡翻譯：「咳嗽兩聲＝第二題……摸兩次左耳＝答案A！」

他正要低頭填答案——

「巫茞輆同學。」

高峙舷老師的聲音，從講台上傳了下來，語氣平淡得像在報告天氣：

「剛才，你總共眨了三次眼，摸了摸兩次耳朵，視線在阿釁同學的位置停留了六秒鐘。根據『語音波形分析』，你剛剛接收到的那組信號，翻譯成暗號是——第二題，答案A，對嗎？」

全班的口罩底下，二十六張臉全部僵住。

高老師走下講台，走到阿釁面前，鏡片後的瞳孔浮現一圈金色的光圈：

「轆慄釁同學，你剛才咳嗽的波形：頻率四百二十赫茲，持續時間零點三秒，聲壓八十五分貝。這個波形，和你練習暗號時的咳嗽，一模一樣。」

他從口袋裡掏出一支筆，在黑板上畫出一道波形曲線：

「各位同學，這就是『暗號識別系統』。咳嗽的聲波，摸耳的動作，鼻子的角度，下巴的弧度——所有信號，都會被記錄、比對、還原。」

「那、那我們……」阿釁的聲音開始發抖。

「還原結果如下。」高老師在黑板上，一筆一劃寫下：

```
摸左耳×2 ＝ 答案 A
摸右耳×2 ＝ 答案 B
摸鼻子×2 ＝ 答案 C
摸下巴×2 ＝ 答案 D
咳嗽 N 聲 ＝ 第 N 題
```

全班看到黑板上的「暗號對照表」，集體倒抽一口涼氣。

老巫嚇得直接把口罩拉起來遮住整張臉，聲音從口罩裡悶悶地傳出來：「老、老師，你是怎麼知道我們用這個的？」

「因為……」高老師放下粉筆，語氣真誠，「你們練習暗號的時候，我正好路過，聽到了完整的『情報』。」

「——！」阿釁整個人僵在原地，臉上的表情像是被雷劈中了一樣。

他萬萬沒想到，自己辛苦設計的暗號系統，竟然在練習的當天，就被高老師完整錄音了！

「還有，」高老師補了一刀，「你們戴著口罩咳嗽，聲波會被布料過濾，音頻更清晰——這在聲學上，叫做『濾波器』。下次要打暗號，建議不要戴口罩。」

「嗚……」阿釁頹然地癱在椅子上。

「砰！」

教室門又被推開，周嚴主任大步衝了進來，臉色緊張：

「怎麼回事！我剛才聽到教室裡『咳咳咳』咳個不停！是不是流感爆發了！」

他環顧四周，看到全班二十六人（包括未晞）都戴著口罩，臉色瞬間刷白：「都、都戴口罩了？！」

「周主任，」高老師面色平靜，「本班正在進行『國語朗讀發音訓練』。咳嗽，是練習聲母『ㄎ』的發聲技巧。」

「練、練習聲母？」周嚴瞪大眼睛，看看高老師，又看看那群戴著口罩、眼神躲閃的學生，「ㄎ？！」

「請聽，」高老師示範，「ㄎ——ㄎ——這是『課』字的聲母。學生們正在集體發音。」

全班默契地齊聲：「ㄎ——！ㄎ——！」

周嚴嘴角抽搐，看了看手上的登記簿，最後還是悻悻然地退了出來：「……神經病啊你們！」

周嚴走後，高老師把黑板上的「暗號對照表」擦掉，重新寫上幾個大字：

「各位，暗號系統雖然失敗了，但它其實很有價值——因為它證明了，你們已經學會『分類整理』。」

他指著黑板：「摸左耳是A、摸右耳是B……這其實就是『把選項分類』的記憶法。與其用暗號傳遞答案，不如把這套分類法，用在整理重點上。」

「老師……」老巫舉手，「那這套暗號表，還有用嗎？」

「有。」高老師微微一笑，把一張印好的「重點分類記憶卡」發給全班，「從今天起，這就是我們的複習口訣。摸左耳，記住A的答案；摸右耳，記住B的答案。考試的時候，你只要摸摸自己的耳朵，就能想起答案。」

「摸自己的耳朵……」老巫半信半疑地摸了摸自己的左耳，「咦？這樣真的想得起來嗎？」

「重點是『記』，不是『摸』。」高老師說。

放學後，考試互助會的緊急會議，氣氛凝重得像喪禮。

「各位……」阿釁雙手抱頭，痛苦地趴在桌上，「我們輸了……徹底輸了……我們的三套作戰計畫，全部陣亡了……」

「阿釁，」晴晴開口，「你有沒有發現一件事？我們每次準備作弊，成績反而都會變好？」

「那只是巧合！」阿釁跳起來，「巧合！你懂嗎！」

「那這次呢？」晴晴問，「這次我們的模擬考，你覺得你能考及格嗎？」

阿釁張了張嘴，卻發現自己竟然……答不出來。

他回想了一下，剛才那場模擬考，雖然整場都在忙著指揮暗號，但那些題目，他好像全都……看得懂？

「這、這不對啊！」阿釁抓著頭髮，「我明明都在想暗號，怎麼會看得懂題目？」

「因為你想暗號的時候，」晴晴平靜地補刀，「把題目也一起看進去了。」

「……」阿釁沉默了整整十秒。

然後，他猛地站起來，握緊拳頭，眼中燃起熊熊鬥志：

「既然人力作弊會被抓，那我們就用——科技！第四號計畫：作弊科技革命，正式啟動！」

「可是阿釁……」老巫弱弱地舉手，「月考……後天就要到了耶。」

阿釁的動作瞬間定格。

他僵硬地轉頭，看了看牆上的月曆——後天，就是月考！

「……科技的事，先放一邊。」阿釁深吸一口氣，語氣突然變得莊嚴，「既然時間來不及了，我們只能動用——最後的殺手鐧！」

「什麼殺手鐧？」老巫緊張地問。

阿釁神秘一笑，湊近全班，壓低聲音：

「人體拼圖。二十六人，一人記一塊。月考當天，拼出完整答案！」
