# 《平行時空的同班同學》時空規則硬設定表

> 全書世界觀的地基。**寫作時一律遵守，不得前後矛盾。** 本表是 RDQ 規格卡「➕ 已採納」的第一項。

---

## 0. 裂縫總覽（「禮堂鏡」）

- 孩子們私下叫它「**禮堂鏡**」——位置在**舊禮堂舞台後方那面沒人用的老鏡子**。
- 本質：兩個世界在某個時刻「共振」時，於鏡面張開的窗口。
- 鏡子平時只是一面蒙塵的老鏡子；裂縫張開時，鏡面會泛起水波般的漣漪，倒映出「另一個世界」的畫面。

---

## 1. 裂縫的開啟

| 項目 | 硬性規則 |
| :--- | :--- |
| **地點** | 舊禮堂舞台後方的老鏡子 |
| **時間** | 每天放學後 **16:05–16:20**（共 15 分鐘）張開 |
| **存續期** | 從第一次張開起算，裂縫總共會開 **7 天** |
| **開啟條件** | 禮堂內沒有大人，且有**至少兩個「看得見的孩子」**在場，鏡面才會慢慢張大 |
| **大人看不見** | **13 歲以下的孩子才看得見**裂縫；大人經過只看見一面老鏡子 |
| **通過限制** | 每次張開**最多同時通過 8 人**，全班 26 人要分批穿越 |

> **年齡分界線設定**：全班 26 人都是 **11–12 歲**，全都看得見。唯有一位「十二歲尾、下個月滿十三」的同學開始「**有點看不清**」裂縫——這是可用的張力點。
>
> **裂縫時間的演進（隨裂痕成長，刻意設計）**：
> - **第 1–5 天**：16:05–16:20，共 15 分鐘。
> - **第 6 天**：提早開、延後關（約 14:30–17:00），且入夜後「關不完全」，鏡面留一道細縫。
> - **第 7 天**：清晨 7 點即開，整天不關，直到午夜永遠閉合。
> - **最後一夜例外**：8 人上限失效——「今晚，鏡子沒有拒絕任何人」（第 16 章）。
> - **投影例外**：進入「時間投影」（記憶裡的開學第三天）後，只有分歧點本人（小林澈）看得見、碰得到兩個林澈；其餘人事物皆是記憶投影，看得見、碰不到。

---

## 2. 穿越與帶物的規則

| 項目 | 硬性規則 |
| :--- | :--- |
| **可穿越物** | 只能「人」穿越；身上穿的、口袋裡的隨身小物可帶 |
| **不可穿越物** | 活物（動物／寵物）不可穿越；大型或非隨身物品不可 |
| **從對方世界帶回** | 小東西可以帶，但**裂縫關閉後會變成「灰色物品」**——不屬於任何世界、摸起來沒有溫度、會慢慢變透明（伏筆／危機點） |
| **穿越去向** | 穿越者從對方世界的「同一面鏡子」出來 |

---

## 3. 待在對方世界的代價（記憶混淆）

| 停留時間 | 代價 |
| :--- | :--- |
| **24 小時內** | 完全正常 |
| **24–72 小時** | 開始「**記憶混淆**」：會想不起自己原本世界的小事（家的門牌、最愛吃的菜、某個同學的綽號） |
| **超過 72 小時** | 分不清哪邊是自己的世界，行為開始「模仿對方世界的自己」 |
| **超過 7 天（裂縫關閉）** | 永遠回不去，會慢慢被對方世界「同化」 |

---

## 4. 世界覆蓋倒數（全書懸念的硬時鐘）

| 天數 | 世界狀態 |
| :--- | :--- |
| **第 1–3 天** | 只有裂縫存在，兩邊世界一切正常 |
| **第 4–6 天** | 開始「**覆蓋**」：某些地方會突然變成對方世界的樣子（例：校門口的小七變回書店、某個同學家多了一個人），**且不可逆** |
| **第 7 天** | 裂縫關閉。若分歧點未處理，關閉瞬間兩邊世界「硬碰」——**其中一邊會被整個抹掉**（誰也不確定是哪邊） |

> 因此全書是一個 **7 天倒數**的硬時鐘，分歧點必須在第 7 天裂縫關閉前處理。

---

## 5. 分歧點與修復

| 項目 | 硬性規則 |
| :--- | :--- |
| **分歧點** | 兩個世界分道揚鑣的那個「**一句話**」的時刻 |
| **修復方式** | **不是改寫歷史**。兩班一起透過裂縫「回到」分歧點當下（時間投影），讓被那句話改變的孩子，同時**看見兩種世界**，理解兩種選擇各自的代價與美好 |
| **和解關鍵** | 那孩子**釋懷的瞬間**，兩個世界「和解」，裂縫安穩關閉，不會有人因此消失 |
| **修復的對象** | 修復的是「兩邊世界的人的執念」，不是「歷史」——所以不會有人被抹掉，但會有人因為想通了而做出選擇 |

---

## 6. 「另一個自己」見面規則（硬性）

1. **可共處**：兩個自己可以同時存在、面對面交談，不會互相排斥。
2. **肌膚碰觸 → 記憶交換**：兩個自己握手／擁抱，會觸發 **3 分鐘的記憶交換**——兩人心靈暫時互通，各自獲得對方人生的一段記憶。（重要劇情工具）
3. **同邊共處上限**：兩個自己待在「同一邊世界」**超過 6 小時**開始同步化（口頭禪、習慣互相靠攏）；**超過 12 小時**其中一個會開始變透明、被覆蓋。→ 兩班因此必須「**輪流回家**」，製造換場邏輯與張力。
4. **規則 3 的解封**：分歧點和解之後，**規則 3 解除**——兩個自己可以長久共處。這正是結局「**有人選擇留下**」之所以能成立的關鍵。

## 7. 寫作時不可違反的清單

- [ ] 裂縫只有 **7 天**；開啟時間隨裂痕演進（第 1–5 天 16:05–16:20 → 第 6 天約 14:30–17:00 → 第 7 天全天）；一次最多 **8 人**（最後一夜例外失效）
- [ ] **大人看不見**裂縫，**13 歲以下**才看得見
- [ ] 停留對方世界 **24h 起記憶混淆**、**72h 起分不清身分**、超過 7 天回不去
- [ ] 覆蓋從 **第 4 天**開始、第 7 天裂縫關閉、未處理則一邊被抹掉
- [ ] 兩個自己 **碰觸＝3 分鐘記憶交換**；同邊 **6h 同步／12h 覆蓋**；和解後此限解除
- [ ] 從對方世界帶回的東西裂縫關閉後變「**灰色物品**」
- [ ] 修復的是「執念」不是「歷史」，沒有人會因此消失
