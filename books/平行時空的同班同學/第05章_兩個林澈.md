# 第 05 章　兩個林澈

九月二十號，星期四。

早自習的時候，林澈一直捏著口袋裡那張紙條。紙條已經被他的手指揉得發軟了。

數學課，老師在講分數的除法。林澈的眼睛看著黑板，腦子裡卻在數鐘錶的秒針。

放學。四點。還有一個下午。

他從來沒有覺得，一天的課這麼長過。

中午打掃時間，晴晴拎著拖把走過來。

「你今天要自己進去？」她問，眼睛看著地板，語氣像在聊今天午餐吃什麼。

「……對。」林澈愣了一下，「你怎麼知道？」

「B 世界的林澈，昨天塞了紙條給你。」晴晴抬起頭，「我看到了。而且你今天一整天都魂不守舍，太好猜了。」

林澈無話可說。

晴晴把一張從筆記本上撕下來的紙塞給他。上面密密麻麻寫滿了她整理出來的規則。

「四點二十分前回來。」她說，「還有——」

「別亂碰『另一個自己』。」林澈接話。

「你知道就好。」晴晴點頭，拎著拖把走了。

阿達從走廊另一端跑過來，湊在林澈耳邊大喊：「要是遇到危險，你就大叫！我們在外面等你！」

「小聲一點啦。」林澈被他嚇了一跳，卻忍不住笑了。

四點零五分。舊禮堂裡，鏡子準時亮起。

銀白色的光，一圈一圈地盪開，像在等他。

林澈一個人站在鏡子前。他深吸一口氣，閉上眼睛，往前走了一步。

涼涼的。耳鳴。然後，所有的聲音都消失了。

再睜開眼睛時，他已經在 B 世界的舊禮堂裡。

而 B 林澈，就站在鏡子前面，笑著看他。

「你真的來了。」

「你約的，不是嗎？」林澈小聲說。

B 林澈笑了起來，領著他走出禮堂。

這個世界的海聲國小，像披著一層溫暖的濾鏡。夕陽的光比他們那邊柔和，風裡的鹹味比他們那邊淡，連牆角的花，都開得比較大朵。

他們經過操場後面的溜滑梯時，B 林澈忽然跳了上去，拍拍旁邊的位置：「坐啊。」

林澈猶豫了一下，爬上去坐好。

兩個一模一樣的男孩，並肩坐在藍色溜滑梯上，腳懸在半空，晃啊晃的。

「你們昨天看到溜滑梯，全都嚇了一跳。」B 林澈說，「所以……在你們那邊，這裡沒有溜滑梯，對吧？」

「嗯。」林澈點頭，「我們那邊，只有一片空地。」

「在我們這邊，什麼都還在。」B 林澈說。

林澈沒說話。他想起晴晴的紀錄：兩個世界的記憶，都開始「對不上」了。

「你要跟我說的，是什麼事？」林澈問。

B 林澈看著遠方的海，沉默了一會。

「開學第三天，體育課。」他開口，「我們班在選大隊接力最後一棒。」

「全班都低頭，沒人敢接。我也是。我從以前就……很安靜。」

林澈愣住了：「你？安靜？」

B 林澈笑了：「聽起來很不可思議吧？可是那天以前，我跟你一樣。坐在窗邊，不講話，不舉手，像教室裡的一片影子。」

「然後呢？」林澈的聲音緊繃起來。

「然後，劉老師走到我面前。」B 林澈說，「他問我：『你想試試看嗎？我看你可以。』」

林澈的心臟，重重地跳了一下。

這句話……他聽過。在夢裡。在舊禮堂的鏡子前。在他想不起來的那一天。

「我接了最後一棒。」B 林澈繼續說，「我跑贏了。全班把我舉起來。從那天以後，我好像變成另一個人。」

「不是變成。」B 林澈轉頭看他，眼睛亮亮的，「是終於敢做自己了。」

林澈低下頭，看著自己的手。

「你們班那天，也選最後一棒嗎？」B 林澈問。

「應該有吧。」林澈說，「可是……我想不起來。」

「想不起來？」

「嗯。」林澈的聲音越來越小，「我只記得陽光很好，記得劉老師吹哨子。其他的……都是霧。」

B 林澈看著他，忽然伸出手，握住了他的手。

「說不定，你只是忘了。不是沒有。」

就在兩隻手碰到的那一瞬間——

世界，亮起來了。

銀白色的光，從兩人的手之間炸開。

然後，記憶像海浪一樣，撲了過來。

林澈看見了。

他看見陽光下，紅色跑道的另一端，接力棒滾到腳邊。他看見自己彎腰接住它，然後，跑。

風在耳邊呼嘯。全班在旁邊尖叫：「林澈！林澈！林澈！」

他看見終點線，看見自己第一個衝過去，看見自己被同學拋上天空。天空好藍，藍得發亮。

那是 B 林澈的記憶。

溫暖的、閃閃發光的、屬於另一個自己的記憶。

畫面一轉。

同樣的操場，同樣的陽光。可是顏色好像淡了一點。

他看見自己站在跑道邊。低著頭。拳頭握緊，又鬆開。

劉老師走到他面前。嘴巴一張一合，正在說話。

可是，聲音像隔著一層厚厚的水。一個字，都聽不清楚。

林澈拼命想聽清楚，想往老師的方向靠近，可是腳像被釘在地上，一動也不能動。

就在畫面快要碎掉的前一刻，他彷彿看見，劉老師的嘴型，做出了三個字。

三個字。

是哪三個字？

下一秒，他醒了。

「哈啊——」

林澈整個人往後彈開，手從 B 林澈的手裡抽出來。兩個人都跌坐在地上，大口大口地喘氣。

「你……也看到了嗎？」B 林澈的聲音在抖。

林澈點頭。他的背全濕了。

「我看到你跑贏了。」林澈說，「全班把你拋起來。天空很藍。」

B 林澈沉默了很久。

「我看到你站在跑道邊。」他慢慢地說，「劉老師在跟你說話。可是……我也聽不到他說了什麼。」

「你的記憶裡，那天缺了一塊。」B 林澈看著他，眼睛裡有心疼。

林澈低頭，聲音很輕：「嗯。」

兩人又沉默了一會。

「沒關係。」B 林澈忽然站起來，拍拍褲子上的灰，朝他伸出手——但伸到一半，又縮了回去，改成比了一個大拇指。

「我們會找到答案的。」他笑，「我們兩個一起。」

林澈看著他。

忽然，他覺得自己好像沒那麼羨慕了。或者說，不是「不羨慕」——是羨慕裡，多了一點別的東西。

他也說不上來那是什麼。

「四點二十分快到了。」最後，他只說出這一句。

B 林澈陪他走回禮堂。

鏡子前，兩人對望。

「明天，我帶你認識我們班所有的人。」B 林澈說。

「好。」

林澈轉身，走進銀白色的光裡。

回到自己的世界時，晴晴和阿達果然等在鐵門外。

「遲到一分鐘！」阿達衝過來，「我們還以為你被鏡子吃掉了！」

「你平安回來就好。」晴晴看著他的臉，皺眉，「你的臉色好白。發生什麼事了？」

林澈笑了笑：「我好像……快想起來了。」

回家的路上，夕陽把海染成金色。

林澈一個人走著，腦子裡都是那三個字。

劉老師的嘴型。三個字。會是什麼？

他走到校門口的便利商店前面，下意識地抬頭看了一眼。

就在那一秒，綠色的 7-ELEVEN 招牌，閃了一下。

在那一閃裡，林澈清清楚楚地看見——招牌變成了藍色的，寫著四個字：

「海聲書店。」

只是一瞬間，就恢復了原狀。

林澈站在原地，心跳得像打鼓。

今天，是第四天。

而世界，開始不對勁了。
