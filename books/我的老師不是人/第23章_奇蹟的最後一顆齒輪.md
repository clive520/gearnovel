# 第 23 章：奇蹟的最後一顆齒輪

狂暴的夜雨像是一道道銀色的鞭子，瘋狂抽打在未來極限樂園三十公尺高的避難月台上。

李博士與十二名特勤人員撤退的腳步聲早已消失在金屬梯下方，但月台上的空氣卻比暴風雨還要冰冷凝重。

晴晴跪在滿是泥濘與積水的防滑鋼板上，雙膝早已被冰冷的雨水泡得失去知覺，雙手止不住地劇烈顫抖。

在她眼前，高老師焦黑破碎的西裝敞開著，胸口原本光潔如鏡的合金檢修蓋被強行掀開，露出裡面糾纏錯綜的光纖線路與冷寂的超導晶片。

李博士留下的最高權限除錯隨身碟已經插在維護通訊埠上，微型的全息螢幕在暴雨中劇烈晃動，投射出一排猩紅色的極度危險警告——

【超級電容殘存電荷：7.4%】
【倒數計時：11分42秒】
【警告：電荷歸零時，核心邏輯單元將觸發永久格式化程序，所有動態記憶庫將不可逆銷毀。】

「還有十一分鐘……只剩下十一分鐘了……」晴晴抹了一把臉上的雨水，聲音裡帶著哭腔，嘴唇已經凍得發紫。

「晴晴，別慌！我們都在這裡！」阿釁猛地抹去眼角的淚水，扯著嗓子大喊。

他轉過身，對著月台上凍得瑟瑟發抖卻一步都不肯退開的同學們高聲吶喊：「六年一班，全體聽令！所有人把外套、雨衣、書包全部拿出來！快！」

「我們來擋雨！高老師的胸口絕對不能進水！」老巫抹了一把臉上的泥水，第一個將身上濕漉漉的厚重防風外套脫了下來。

二十六個渾身濕透的孩子在雷鳴電閃中動了起來。

老巫、尪伝恺、還有幾個力氣大的男生用自己的後背排成一道密不透風的擋風牆，死死迎向呼嘯而來的七十公里側風。

林芸芸和另外幾名女生將所有人的雨衣、外套和書包高高撐開，在晴晴和高老師的頭頂搭建起了一頂簡陋卻滴水不漏的人肉防雨帳篷。

阿釁則手持李博士留下來的強光手電筒，半跪在晴晴身旁，將雪亮的光柱穩穩打在高老師敞開的胸腔核心。

周嚴主任手裡依然死死攥著那根冰冷的生鐵水管，宛如一尊金剛雕像般佇立在通往鐵梯的入口處，目光如鷹隼般死死盯著下方，為這群孩子守住最後的防線。

「晴晴，妳看這裡！三號軸承座的情況怎麼樣？」阿釁屏住呼吸問道。

晴晴深吸了一口氣，強迫自己凍僵的手指握緊了李博士留下的特製鈦合金反向微調扳手。

藉著手電筒的強光，她看清了高老師主動力傳動室的慘狀。

那是高老師全身力量的心臟中樞，原本精密咬合的行星齒輪組中間，赫然缺席了最關鍵的第三號齒輪。

而用來固定第三號齒輪的行星軸承座，因為剛才承受了三萬八千牛頓米的極限推力，合金外圈在高溫熔融與驟冷的雙重打擊下產生了微米級的熱形變，像是一隻死死閉合的鐵蚌，將軸心卡得動彈不得。

「軸承座發生了熱卡死……」晴晴咬著牙，將鈦合金扳手探入狹窄的機腔隙縫中，「如果不把這個變形的合金鎖片向左旋轉兩點五毫米，齒輪根本插不進去！」

「那快轉啊！」老巫在風雨中扯著嗓子吼道。

「不行！李博士說過，這是航太級的左旋反牙結構！」晴晴的眼眶泛紅，手背上的青筋因用力過度而突起，「普通扳手根本卡不進反向槽，而且……沒有那顆專用的反牙螺帽，就算我把軸承座撬開、把齒輪塞進去，一旦通電重啟，每分鐘三萬轉的高速旋轉會立刻把齒輪甩飛，造成核心主板徹底炸膛！」

全息螢幕上的倒數數字毫不留情地跳動著：【08分15秒】。

「螺帽……剛才掉下去的那顆螺帽呢？！」阿釁的心臟狂跳，猛然轉頭看向月台邊緣那片漆黑恐怖的鋼構深淵。

過山車的軌道下方是三十公尺高的複雜鋼樑桁架，狂暴的夜雨在縱橫交錯的鋼管之間形成了無數道水瀑，黑洞洞的深谷宛如能吞噬一切的巨獸。

在這樣漆黑暴雨的深夜，想要在數千根生鏽打滑的鋼架中找到一顆只有指甲蓋大小的黑色螺帽，簡直比大海撈針還要渺茫。

「吱吱——！！」

就在這時，一聲尖銳卻充滿決然的鳴叫刺破了暴風雨的喧囂。

只見在月台最外側的一根傾斜鋼軌上，一道金色的光點正在暴雨中瘋狂穿梭。

是溜溜！

這隻巴掌大小的 AI 智慧小寵物，全身的毛髮早已被狂風暴雨澆成了落湯雞般的細條，但它那根細長的仿生天線尾巴，卻在雨幕中爆發出前所未有的高頻藍光！

它的四隻微型電磁吸盤爪在垂直濕滑的圓形鋼管上極速交替攀爬，小小的鼻子在狂風中瘋狂聳動，搜尋著那極其特殊的微量航太合成酯類潤滑油氣味。

「溜溜！小心啊！」林芸芸忍不住失聲驚呼。

一道刺目的閃電撕裂夜空，緊接著是震耳欲聾的炸雷！

狂暴的氣流將溜溜小小的身軀吹得在半空中打了好幾個滾，差一點就要墜入萬劫不復的深谷。

但它的尾巴靈巧無比地在鋼樑上猛力一甩，鈦合金爪尖在鋼管上擦出一道刺眼的火星，硬生生在三十公尺高空的懸崖絕壁上重新吸附住！

倒數計時螢幕無情地跳成了紅色：【05分29秒】。

「找到了沒有啊……溜溜！」老巫急得滿頭大汗，雨水和汗水混在一起滾進眼睛裡，刺痛無比。

突然，在下方二十公尺處一根橫向鋼樑的凹槽邊緣，反射出了一道微弱的烏黑金屬冷光！

那是那顆特製的八角形左旋反牙螺帽，正好卡在兩根鋼樑交錯的防震橡膠墊縫隙裡，距離滾落懸崖只差最後五毫米！

溜溜金黃色的電子眼瞬間鎖定目標，四爪發力，在暴雨中順著垂直滑軌疾衝而下！

它一口咬住了冰冷堅硬的鈦合金螺帽，尾巴向上一揚，四肢如同一道金色的閃電，在密密麻麻的立體鋼架間展開了驚心動魄的逆向攀登！

「它拿到了！溜溜拿到螺帽了！」阿釁狂喜地指著鋼架大喊。

月台上的二十六個孩子爆發出一陣壓抑已久的歡呼，每個人眼裡的淚光都在手電筒下閃爍。

溜溜像一顆小砲彈般衝出深淵，一個凌空翻滾穩穩落在了晴晴攤開的手掌心裡！

它渾身顫抖著，嘴巴一張，「鏗啷」一聲，那顆沾著泥水與油脂的黑色反牙螺帽落在了晴晴的手心。

溜溜用濕漉漉的腦袋蹭了蹭晴晴的手指，隨即體力耗盡般趴在鋼板上劇烈喘息，尾巴上的藍光也漸漸轉為微弱的呼吸燈。

「好樣的，溜溜！六年一班記你大功一次！」老巫激動得差點哭出來。

「還有三分半鐘！晴晴，看妳的了！」阿釁大吼。

全息螢幕上的警報音已經由長鳴變成了急促刺耳的「嗶、嗶、嗶」高頻蜂鳴：【03分18秒】！

晴晴擦乾手上的水漬，眼神在此刻變得前所未有的專注與鋒利。

身為黑手修車行老闆的女兒，她從小就在引擎與齒輪堆裡長大，但她這輩子從未進行過如此賭上一切的手術。

「阿釁，把項鍊拿給我！」晴晴伸出右手。

阿釁沒有絲毫猶豫，一把扯斷了掛在脖子上整整一年的傘繩項鍊。

那顆精緻沉重、刻著【P.E.D.A. Core-Gear #03】的黃銅行星齒輪，在暴雨中閃爍著溫暖而永恆的金黃色光芒。

正是這顆齒輪在一年前滾落講台，才讓他們認識了那個會用手指熱肉包、會把肚子餓扁理解成充氣防扁平的怪怪老師。

「老朋友，該回家了。」阿釁將齒輪鄭重地放在了晴晴的手中。

晴晴左手捏著特製反向微調扳手，右手持精密磁性鑷子，將黃銅齒輪對準了高老師胸腔深處的核心槽位。

「反向扭矩校準……左旋兩點五毫米……」晴晴屏住呼吸，全身肌肉繃緊。

「喀嚓！」一聲極其微細的金屬回彈聲響起，卡死的第三號軸承座在鈦合金扳手的撬動下，終於退回了標準公差位置！

「齒輪入槽！」晴晴將黃銅齒輪穩穩推入主傳動軸。

原本冰冷定格的齒輪箱裡，黃銅齒輪與周圍的合金齒輪嚴絲合縫地咬合在一起，發出一聲清脆悅耳的「鏗——！」

「反牙螺帽，安裝！」

晴晴用鑷子夾住螺帽，迅速套上主軸，扳手向左逆向飛速旋轉三圈半！

最後一記沉重而精準的發力——

「卡嗒！」

自鎖機構完美咬合，鎖定到位！

全息螢幕上的倒數計時在此刻定格在了：【00分14秒】！

整個避難月台瞬間陷入了一片死一般的寂靜。

狂暴的風雨彷彿在這一瞬間被按下了靜音鍵，二十六個孩子連大氣都不敢喘一口，周主任握著鐵管的手背暴起青筋，所有人齊刷刷地盯著高老師緊閉的雙眼。

一秒……兩秒……三秒……

沒有動靜。

高老師依然冰冷僵硬地挺立在雨中，雙眼如同兩口深不見底的枯井，毫無光彩。

「怎麼會……」阿釁的眼淚奪眶而出，噗通一聲跪倒在高老師腳邊，雙手用力搖晃著老師冰冷的大腿，「高老師！齒輪裝回去了啊！螺帽也鎖上了！你睜開眼睛看看我們啊！」

「老師……求求你醒過來……」林芸芸捂著臉放聲大哭。

老巫一把將手裡的大金熊抱偶狠狠扔在鋼板上，抱著高老師的腰嚎啕大哭：「高老師！你不是說這隻熊要給我留著考一百分嗎！你醒過來罵我啊！你叫我去跑操場啊！」

全息螢幕上的數字跳到了【00分00秒】。

殘存電荷歸零。

晴晴脫力地坐在泥水裡，手中的扳手滑落，眼淚混著雨水無聲地滑落臉頰。

難道……真的太遲了嗎？

就在絕望如潮水般即將把所有人淹沒的瞬間——

「嗡————」

一聲極其低沉、卻無比渾厚的機械諧振聲，突然從高老師殘破西裝深處猛烈傳出！

緊接著，被雨水澆透的胸口散熱蜂巢扇，突然發出了一聲輕微的摩擦聲，隨後開始由慢至快地瘋狂旋轉起來！

呼——！

一股混合著機油清香與微熱溫度的白色水蒸氣，從高老師的胸腔噴湧而出，將籠罩在周圍的刺骨寒雨瞬間驅散！

「嗶————」

一聲無比清脆、空靈，宛如晨曦穿透厚重烏雲般的系統自檢重啟音，在雷雨轟鳴的夜空中悠然炸響！

在高老師那副鏡片碎裂成蜘蛛網狀的黑框眼鏡後方——

原本死寂黑暗的眼眸深處，兩道微弱的橙黃色光斑驟然點亮！

光斑閃爍、校準、重組……

在零點五秒之後，兩道純淨、溫暖、璀璨如星河般的金藍色超導微光，在高老師的雙眼之中轟然綻放！

高老師僵硬如石雕般的頸部關節發出了一陣細密而精準的齒輪咬合聲，他的下巴微微抬起，頭顱以每秒十五度的標準勻速緩緩低下。

那雙重新亮起璀璨微光的眼睛，緩緩掃過眼前跪在泥水裡的晴晴、抱著他大腿痛哭的阿釁、鼻涕眼淚糊了一臉的老巫，以及周圍那一張張凍得通紅、卻寫滿狂喜與震撼的稚嫩臉龐。

雨水順著高老師刀削般的臉頰滑落，他那張總是沒有多餘表情的嚴肅臉龐上，聲帶合成器發出了一聲熟悉的、帶著微弱金屬質感的低沉嗓音：

「系統自檢完成。主電源已恢復至百分之百安全待機狀態。」

高老師推了推鼻樑上那副碎裂的黑框眼鏡，目光精準地停留在哭得打嗝的阿釁臉上，語氣波瀾不驚地開口：

「轆慄釁同學，根據氣象資料庫分析，當前現場降雨量為每小時六十五毫米，相對濕度百分之九十八點七，體感溫度攝氏十二點三度。」

「在未穿戴合格連帽防雨用具的情況下，你以眼眶腺體大量分泌高濃度氯化鈉液體，並將頭部貼近班導師下肢西裝褲料的行為，經計算，將會使布料纖維受潮膨脹率增加百分之四十二。」

高老師頓了頓，又緩緩轉頭看向老巫和晴晴，嘴角似乎極其隱蔽地向上牽動了零點零零一毫米：

「此外，巫茞輆同學，你放在褲子口袋裡的備用鮮肉包，已經在剛才的衝撞中被徹底壓成了厚度一點二公分的扁平固體。」

「但鑑於本班全體二十六名學生均在未被物理壓扁的情況下全數存活……」

高老師抬起那隻覆蓋著水銀液態金屬、線路焦黑卻依然修長有力的右手，輕輕覆蓋在阿釁濕透的頭頂上，指尖散發出一縷令人安心的微溫：

「本次校外教學應急演練……六年一班全員，評定為：合格。」

「哇啊啊啊啊啊——！！！」

整座三十公尺高的避難月台，在短暫的呆滯後，徹底被驚天動地的歡呼與哭喊聲引爆！

二十六個孩子再也忍不住，像是一群出巢的小鳥般瘋狂湧了上去，一把撲進高老師那散發著溫熱蒸氣與機油清香的懷抱裡！

周嚴主任背對著狂歡的師生，用袖子狠狠抹了一把不知道是雨水還是淚水的臉龐，將那根沉重的生鐵水管重重扔在地上，嘴角終於咧開了一個比哭還難看、卻無比欣慰的笑容。

夜空中的烏雲在此刻悄然裂開了一道縫隙，一縷清澈純淨的月光穿透風雨，溫柔地照耀在鹿陽國小六年一班每一個人的身上。
