# 《少年科幻解謎電子書網》網站建置計劃書

## 一、專案背景與願景

### 1. 專案背景
本專案旨在為優質原創的兒少中長篇小說打造一個專屬的**現代化網站電子書閱讀平台**。首期以已完結之第一部長篇小說《記憶黑客少年：校園地下 404 室》（共十章）為旗艦作品，後續將無縫擴充第二卷《千島齒輪海的迷失燈塔》及其他多元冒險、科幻與解謎系列的書籍，建構一個屬於孩子們的優質故事殿堂。

### 2. 核心受眾
* **主要讀者**：國小中年級至國中一年級（約 9～13 歲），喜愛科幻冒險、校園偵探、機械解謎的少年讀者。
* **次要受眾**：家長與國小閱讀推廣教師（注重閱讀安全、字體護眼、無廣告干擾與知識啟發）。

## 三、網站核心內容規劃

網站將採用「主題書庫＋沉浸式閱讀＋世界觀圖鑑＋互動解謎」四維一體的架構：

```
[ 首頁 Home ]
  ├── 📖 [ 書庫總覽 Book Library ]
  │     ├── 《記憶黑客少年：校園地下 404 室》（第 1 本 · 完結）
  │     ├── 《千島齒輪海的迷失燈塔》（第 2 本 · 預告）
  │     └── [ 未來擴充書架…… ]
  ├── 📜 [ 電子書沉浸閱讀器 Reader ]（1~10章，含進度保存與排版控制）
  ├── 👥 [ 齒輪鎮角色與檔案誌 Codex ]（人物卡、道具庫、地底地圖）
  └── 🧩 [ 少年密碼動腦實驗室 Puzzle Lab ]（書中出現的真實密碼互動體驗）
```

### 1. 首頁（Home / Showcase）
* **主視覺橫幅（Hero Section）**：精美呈現第一部旗艦小說的冒險宣傳，一鍵「開始閱讀第一章」按鈕。
* **藏書展示架（Bookshelf）**：
  * 當前主打書（封面、簡介、標籤：#科幻 #解謎 #校園 #齒輪）。
  * 「即將推出」預告書位，展現平台持續擴展的生命力。
* **故事特色速覽**：懸念劇情、硬核真實密碼學、成長與勇氣核心價值。

### 2. 書籍主頁與目錄（Book Overview & Table of Contents）
* **書籍檔案卡**：書名、字數、章節數、適合年齡、內容大綱。
* **章回清單**：第一章至第十章的章節名稱與劇情提要，清晰標示「已讀 / 未讀」狀態。
* **進度記憶**：自動記錄讀者上次閱讀到的章節與位置，提供「繼續閱讀」按鈕。

### 3. 沉浸式電子書閱讀器（Interactive Reader）
* **少年友善排版**：
  * **字級調整**：大 / 中 / 小 三段字體切換，預設字體微大，行距舒適寬鬆。
  * **主題背景**：白天模式（護眼紙張白）、羊皮紙模式（溫潤復古）、深色夜間模式（柔和不刺眼）。
  * **章節導航**：底部固定「上一章 / 目錄 / 下一章」快捷切換，支持鍵盤左右箭頭翻頁。
* **密碼互動彈窗（Puzzle Notes）**：
  * 閱讀到正文中的密碼段落時（如 A1Z26、質數鎖、杜威索書號、布林邏輯、奇偶校驗），可點擊查看「小偵探密碼小百科」，以圖解方式幫助小讀者理解原理。

### 4. 角色圖鑑與裝備庫（Characters & Codex）
* 將設定集中的人物（誠浩、葉旖緁、皮可、邱校長、高老師、將江）製作成可翻轉的立體精美卡片。
* 展示「皮可的三種變形型態」與「爺爺的幽靈護目鏡功能分解圖」。

## 五、技術架構與建置規劃

### 1. 技術選型建議
* **前端核心**：現代輕量前端技術（HTML5 + Tailwind CSS + Vanilla JS / 或 React/Vue 輕量單頁應用）。
* **內容引擎**：直接解析現有專案目錄下的 Markdown 檔案（`chapters/*.md`），寫作與網站同步，維護最省力。
* **儲存機制**：瀏覽器原生 `localStorage`，無需伺服器資料庫即可實現無縫進度記憶。
* **部署平台**：支援免費一鍵發布至 GitHub Pages、Vercel 或本機離線免安裝運行。

### 2. 階段里程碑規劃

* **第一階段（骨架與首本上線）**：
  * 建立網站基礎架構與視覺風格（科幻齒輪與溫暖藍金主色調）。
  * 導入第一本書《記憶黑客少年：校園地下 404 室》全十章與人物圖鑑。
  * 完成核心閱讀器（進度記憶、字體縮放、換章導航）。
* **第二階段（互動與閱讀體驗深化）**：
  * 加入章節密碼彈窗小百科與閱讀徽章系統。
  * 支援平滑手機/平板觸控滑動翻頁。
* **第三階段（多書擴充庫上線）**：
  * 推出書庫總覽分類篩選功能。
  * 預載第二卷《千島齒輪海的迷失燈塔》前導預告。
